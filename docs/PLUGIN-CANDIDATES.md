# 플러그인 후보와 후속 작업 지침

작성: 2026-10-11. 상태: 개략 계획. 구체적인 API·UI·범위는 구현 담당자가 최신 코드와 공급자 자료를 확인해 확정한다. 이 문서는 플러그인 개발·설치·외부 배포를 실행한 기록이 아니다.

내장 기능 계획은 [다음 버전 계획](NEXT-VERSION-PLAN.md)을 따른다. 개인 추천·서버 저장·건너뛰기 엔진을 플러그인에 중복 구현하지 않는다.

## 공통 기반

- `docs/PLUGINS.md`와 현재 `WebsitePlugins.tsx`, 서버 `website-plugins.ts`를 먼저 읽는다.
- home/detail 배치, `moa.ui.resize`, 허용된 외부 origin의 `moa.fetch`, MOA 검색으로 이동을 활용한다.
- `app.context`는 페이지 경로, `player.context`는 현재 회차/제목/재생 위치다. 작품 메타데이터나 전체 기록을 주는 권한으로 오해하지 않는다.
- `catalog.transform`은 제한된 표시 필드 수정용이다. 정보 조회를 위한 가짜 변환이나 숨은 기록 수집 경로로 쓰지 않는다.
- API 키를 ZIP/JS에 포함하지 않는다. 기존 MOA 키를 쓰려면 필요한 메타데이터만 반환하는 호스트 API를 설계하고 원문 키는 플러그인에 주지 않는다.
- 플러그인별 connect, 최소 MOA/API 버전, 출처 표시, 오류/빈 결과/캐시 갱신을 명시한다. 새 권한/API가 필요하면 해당 기능을 제공하는 호스트 버전을 minMoaVersion에 선언한다.
- 현재 `moa.fetch`는 URL 기반 GET이고 임의 헤더/POST를 전달하는 일반 HTTP 클라이언트가 아니다. GraphQL이나 인증 헤더가 필요한 공급자는 실제 GET 지원 또는 제한된 호스트 어댑터를 확인하며, 필요하다는 이유만으로 unrestricted fetch 권한을 추가하지 않는다.
- 외부 플러그인 iframe의 포스터·목록은 기존 MOA 카탈로그 키즈 필터가 자동 적용되지 않는다. 가족 계정에 제공할 플러그인은 호스트의 프로필 정책을 적용하는 데이터 계약을 사용하고, 지원 전에는 키즈 프로필에서 노출하지 않는 방향을 검토한다.
- 외부 목록의 작품이 설치된 소스에서 재생 가능하다는 보장은 없다. 첫 구현은 상세 정보 또는 제목 검색으로 연결한다.
- UI는 Opus 5.5 담당자에게 사용자 목적과 상태 계약을 전달하고 구체적인 레이아웃을 미리 강요하지 않는다. 홈 높이·모바일 조작·스포일러·접근성은 검토한다.
- 개인 사용 플러그인은 별도 작업/배포 의사를 확인하며, 사이트별 비공개 확장은 공개 앱 문서·패키지에 포함하지 않는다.

## 1. 요즘 인기 영화·드라마

목표: 홈에서 최근 볼만한 작품 발견. 후보 중 가장 먼저 만들기 좋다.

- TMDB 일간/주간 트렌드, 영화/TV 분류, 한국어 제목·포스터·소개.
- ‘한국어 표시’와 ‘한국 내 인기 순위’를 구분한다. 실제 OTT 시청 순위라고 표현하지 않는다.
- 범위가 필요하면 한국 제작 작품/장르 필터를 검토한다. 필터가 API에서 가능한지 확인한다.
- 카드 선택 시 MOA 검색. 확인된 기존 작품 연결 API가 생기면 직접 상세 연결 가능.
- 키/캐시를 호스트에서 공유하는 접근이 유력하다. 인증키 없는 개인 프록시를 공개하는 방식은 쓰지 않는다.
- 같은 후보를 추천 내장 기능이 쓰더라도 화면과 의미는 분리한다.

확인할 것: TMDB 키의 현재 보관 위치와 제한된 조회 API, 이미지 표시 경로, 공급자 출처 표시, 중복/빈 결과.

## 2. 영화 개봉·드라마 방영 일정

목표: 오늘/이번 주 공개되는 작품과 다음 회차 날짜 확인.

- 영화: TMDB의 개봉 예정/지역별 날짜. 극장 개봉과 스트리밍 공개를 혼동하지 않는다.
- 드라마: TVmaze 방송/스트리밍 일정, TMDB TV/회차 데이터 후보.
- 한국 드라마·해외 작품·글로벌 OTT 표본으로 수록률/시간대/다중 회차 공개/일정 변경을 먼저 확인한다.
- Asia/Seoul 표시와 원본 시간대를 구분하고 날짜만 있는 데이터에 임의 시간을 붙이지 않는다.
- 최초 목표는 홈 일정 패널. 외부 푸시·이메일·사용자 알림 서버는 필요하지 않다.
- 데이터가 부정확한 경우 ‘방영 예정’ 수준으로 표시하고 소스 업로드 완료처럼 설명하지 않는다.

확인할 것: TVmaze 무료 API/라이선스·캐시 조건, 국내 표본, TMDB 결과와 중복 처리. 전체 편성표 수집이나 웹 크롤러부터 만들지 않는다.

## 3. 국내 박스오피스

목표: 국내 극장 기준의 일별/주간 인기 영화 표시.

- KOBIS 순위·관객 수·개봉일, 필요 시 TMDB 포스터를 조합한다.
- 제목+연도 등으로 작품 매칭을 확인하고 모호한 결과는 포스터를 잘못 붙이지 않는다.
- API 키는 서버에서 관리하고 화면에는 출처와 조회일만 표시한다. OTT 순위와 별도 기능이다.
- ‘요즘 인기’ 플러그인의 탭으로 합칠지 독립 패키지로 둘지는 데이터/사용성 확인 후 결정한다.

## 4. 성우·출연진·제작진 상세 탐색

목표: 작품 상세에서 인물과 다른 참여 작품을 찾아보기.

- 기존 TMDB 통합은 출연진 이름·배역·사진 일부를 보유한다. 기본 정보는 호스트 메타데이터 보강으로, 깊은 탐색은 detail 플러그인으로 나누는 안이 유력하다.
- TMDB의 cast/crew, AniList의 캐릭터·성우·제작진·제작사 자료를 후보로 한다.
- 역할별 목록, 캐릭터 ↔ 성우, 인물 참여 작품을 우선한다. 인물 선호/구독 알림은 후순위.
- TV aggregate credits는 시리즈 전체 자료일 수 있다. 시즌·회차 출연으로 오인하지 않게 데이터 범위를 표시한다.
- 한국어 이름과 한국어 더빙 참여는 별개다. 원어/더빙 언어·시즌 판본을 구분하고 자료 없는 항목을 추측하지 않는다.
- 현재 작품의 확정 외부 ID와 허용된 메타데이터를 읽는 호스트 계약이 필요하다. 제목만으로 매번 재매칭하거나 플러그인에서 내부 API/DB를 우회하지 않는다.
- “내가 본 작품 중 이 인물의 작품”은 다음 버전 필수 범위가 아니다. 필요 시 최소 프로필 데이터 조회 권한을 별도 검토한다. 내장 추천 개발을 이유로 모든 플러그인에 기록을 개방하지 않는다.

## 5. 찜한 작품의 다음 시즌·회차

목표: 관심 목록에 있는 작품의 방영 예정 정보를 모아서 표시.

- 작품의 외부 ID, 관심 목록의 읽기 전용 권한이 필요하다.
- 현재는 권한/API 미구현이므로 일정표와 관심 목록 연결 기반 이후로 미룬다.
- 날짜 변경/미정 처리, 중복 시즌, 프로필 격리를 확인한다. 알림은 사용자가 요청하기 전까지 추가하지 않는다.

## 실행 순서와 인계

권장 순서: 인기 패널 → 성우/제작진 → 일정표 → 관심 작품 일정. 국내 박스오피스는 별도 수요에 따라 선택한다.

각 작업자는 착수 시 아래만 확정한 후 구현한다.

1. 기존 플러그인 API만으로 가능한지, 최소 호스트 기능이 필요한지.
2. 공급자의 공식 계약·키·출처·수록 범위와 소수 실제 결과.
3. 최소 표시 기능, 실패/빈 결과, 모바일 동작.
4. 합성 응답 검사와 데스크톱/모바일 1회 확인. 운영에 자동 설치하거나 배포하지 않는다.
5. 산출물에 지원 MOA 버전, 설치 방법, 데이터 한계, 다음 담당자가 확인할 항목을 기록한다.
