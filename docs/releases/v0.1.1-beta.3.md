# MOA v0.1.1-beta.3

프로필별 자막 설정과 플러그인 사용 흐름을 개선하고 설정 화면을 정리한 베타입니다.

## 변경 사항

- 자막 선택을 프로필별로 서버에 저장하고, 묶인 작품의 같은 회차에서도 재사용합니다. 기존 브라우저에만 저장된 선택은 서버에 선택이 없는 경우에 이전합니다.
- 업로드·온라인·번역 자막 관리와 회원의 시청·자막 추가·번역 권한 설정을 추가했습니다.
- 자막 모양에 실시간 미리보기와 슬라이더를 제공하고, 값을 입력한 뒤 필드를 닫아도 변경이 보존되도록 수정했습니다.
- 설정 메뉴를 작업별로 정리하고 좁은 화면의 탐색을 개선했습니다.
- 활성화된 HTML 플러그인을 일반 회원도 메뉴에서 실행할 수 있도록 수정했습니다. 플러그인 설치·삭제는 관리자 전용입니다.
- 플러그인의 실행 훅과 주간 일정 예제를 보강했습니다. 플러그인은 별도로 설치·활성화해야 합니다.
- UI 후속 변경에서 발생한 CSS 빌드 오류를 수정했습니다.

## 업데이트 및 범위

- 베타 채널에서 확인 후 직접 설치할 수 있습니다. 정식 채널은 v0.1.0을 유지합니다.
- 기존 시청 기록과 확장 설정을 유지합니다. 사이트별 비공개 확장과 사용자 데이터는 배포에 포함하지 않습니다.
- 자막 저장용 테이블과 계정 권한 열을 추가합니다. 합성 데이터로 새 코드 초기화 후 beta.2 앱·인증 런타임의 재시작과 기존 기록 보존을 확인했습니다.
- 설치 실패 시 이전 이미지로 복구할 수 있습니다. 새 권한·자막 기능을 사용한 뒤 수동으로 구버전으로 내리면 구버전은 새 기능을 인식하지 못하므로 권장하지 않습니다.
- 모바일 PiP 자막 개선과 실험 중인 HTTP 기반 WebView 대체는 포함하지 않았습니다.
