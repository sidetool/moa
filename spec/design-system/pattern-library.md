# 화면 구성

공통 UI를 조합해 같은 흐름을 유지합니다. 화면마다 별도 구현을 복사하지 않습니다.

## 설정 저장

`features/settings/`의 번역·네트워크·자막 설정에 적용합니다. 이름과 설명 뒤에 값을 배치하고 좁은 화면에서는 조작 영역을 줄바꿈합니다. 패널에는 `min-width: 0`을 유지합니다.

입력·`Select`·`Toggle`·`Button`을 사용하며 초안·저장 요청·오류는 기능 모듈에서 관리합니다. 저장 중에는 중복 제출을 막고 실패하면 초안을 유지합니다. 오류를 입력에 연결하고 완료는 `role=status`로 알립니다. 키보드는 필수 입력→보조 동작→저장 순서로 이동합니다.

아래 예제는 서버와 프로필을 바꾸지 않고 입력 오류·저장 중·완료 상태를 보여 줍니다.

## 다음 화 안내

엔딩 구간 정보가 있는 회차는 그 정보에 맞춰 다음 화 카드를 띄웁니다. 정보가 없는 영상은 재생 설정의 ‘재생 고급설정’에서 정한 시간만큼 끝나기 전에 띄우며, 0초면 영상이 끝난 뒤 띄웁니다. `apps/web/src/features/settings/PlaybackAdvancedSettings.tsx`에 적용합니다.

값은 `NumberStepper`로 바꾸고 잠시 뒤 자동 저장합니다. 설명 아래에는 자동 재생 설정과 합친 결과를 한 문장으로 보여 줍니다. 저장에 실패하면 이전 값으로 되돌린 뒤 이유와 ‘다시 시도’를 함께 표시합니다.

다음 화 카드의 닫기 버튼은 닫은 뒤 보게 될 내용을 이름으로 씁니다. 엔딩 구간 안에서는 ‘엔딩 보기’, 엔딩 정보 없이 미리 띄웠거나 엔딩 뒤 장면이 남았으면 ‘계속 보기’, 영상이 끝난 뒤에는 ‘닫기’입니다.

## 기존 자막 설정 유지

ASS 원본 효과 유지는 직접 켰을 때만 적용합니다. 설정값이 없는 기존 기기는 저장된 자막 크기·그림자·외곽선을 계속 사용합니다. 원본 효과를 켜면 사용자 모양 조절을 비활성화하고, 다시 끄면 저장된 값을 복원합니다. 아래 예제는 새 설정값 없이 크기 150%·그림자 3px을 저장한 기기입니다.

## 다운로드를 끈 작품 화면

서버 다운로드가 꺼졌거나 저장소가 준비되지 않았으면 작품의 영화·개별 회차·전체 회차 다운로드 버튼과 설정 유도 링크를 숨깁니다. 설정 화면에서 켜고 저장소가 준비된 뒤에만 표시합니다. 끈 상태로 돌아오면 새로고침 없이 숨깁니다.

```preview
download-visibility
```

## 검색과 필터

`apps/web/src/pages/SourcesPage.tsx`와 `apps/web/src/features/sources/SourceFilters.tsx`에 적용합니다. 필터 이름과 값을 함께 표시하고 다중 선택은 `Select`의 `multiple` 모드를 사용합니다. 정렬에는 `SegmentedControl`을 사용합니다.

로딩·실패 후에도 입력을 유지하며 같은 조건으로 다시 시도할 수 있게 합니다. 결과가 없으면 필터 초기화를 제공합니다. 초기화는 해당 필터에만 적용하고, 팝업 목록은 일반 문서의 `ul`·`li` 스타일을 물려받지 않습니다.

```preview
filter-pattern
```

## 삭제 등 중요한 작업

계정·자막 삭제와 탭 초기화는 작업 버튼→`ConfirmDialog`→취소 또는 확인→결과 순서로 진행합니다. 대상과 결과를 짧게 설명하고 취소에 처음 포커스를 둡니다. 요청 전에는 Escape·바깥 클릭으로 취소할 수 있으며 요청 중에는 닫기와 중복 요청을 막습니다. 실패하면 모달 안에 오류와 재시도를 표시합니다.


## 홈 편성표 플러그인

요일별 신작은 큰 포스터 아래에 방영 시간과 제목을 표시합니다. 가로 스크롤바 대신 포스터 높이에 맞춘 화살표 버튼을 목록 양끝에 여백 없이 붙여 한 화면씩 이동합니다. 버튼은 폭 48px이며 테두리 없이 32px 화살표를 가운데 표시합니다. 안쪽 모서리에만 12px 둥글기를 적용합니다. 이전 버튼은 오른쪽 위·아래, 다음 버튼은 왼쪽 위·아래를 둥글게 표시합니다. 더 이동할 수 없는 방향의 버튼은 숨기며, 반대쪽 버튼의 위치는 유지합니다. 제목은 두 줄까지 표시합니다.

마우스 화면에서는 포스터 목록에 마우스를 올렸을 때 화살표를 표시하며, 키보드의 `:focus-visible` 상태에서도 표시합니다. 터치 화면에서는 이동 가능한 화살표를 항상 표시합니다. 나타나고 사라질 때는 240ms 페이드를 사용합니다. 마지막 페이지에 도달하면 클릭은 즉시 막고 페이드가 끝난 뒤 버튼을 숨깁니다. 동작 줄이기 설정에서는 지연 없이 표시하거나 숨깁니다.

요일은 최대 52px 원형 버튼을 왼쪽에 모아 표시합니다. 패널이 380px 이하이면 48px 크기를 유지해 4개·3개 두 줄로 왼쪽 정렬합니다. 방향키·Home·End로도 요일을 바꿀 수 있습니다.

홈을 열면 오늘의 편성표를 먼저 표시하고 모든 요일의 작품 정보와 포스터를 제한된 수만큼 병렬로 미리 불러옵니다. 같은 작품과 이미지는 재사용하며, 새로고침 후에도 서버의 유효한 이미지 캐시를 사용합니다. 포스터가 준비될 때까지 같은 크기의 스켈레톤을 표시하며, 이미지가 없거나 실패하면 스켈레톤을 멈추고 시간과 제목을 유지합니다. 동작 줄이기 설정에서는 스켈레톤과 페이지 이동 애니메이션을 끕니다.

작품이 확인되면 상세 페이지로, 없거나 모호하면 검색으로 이동합니다. 이미지 조회 중 요일을 바꾸어도 이전 이미지가 섞이지 않아야 합니다. 플러그인 iframe에서는 공통 UI를 직접 가져올 수 없으므로 호스트의 색상 변수와 기존 플러그인 패턴을 사용합니다.

아래 미리보기는 실제 플러그인 코드에 예시 편성표와 이미지만 제공합니다. 외부 서버나 계정에는 접근하지 않으며, 작품을 누르면 이동할 경로를 표시합니다.

```preview
anime-schedule
```

## 플레이어 배속 안내

배속 배지는 화면 위쪽 중앙에 표시하며 상단 안전 여백 아래 56px에 놓습니다. 760px 이하 화면에서는 세 줄 제목과 겹치지 않도록 68px에 놓습니다. 반투명 블러 배경을 유지해 영상과 구분합니다. 아래 미리보기는 플레이어의 실제 배지 스타일을 사용합니다.

```preview
player-feedback
```

재생 중 영상 화면이나 스페이스를 450ms 이상 누르면 기기에 설정한 길게 누르기 배속을 적용합니다. 누른 채 마우스를 움직여도 유지하고, 놓거나 창이 비활성화되면 원래 속도로 돌아갑니다. 스페이스를 짧게 누르면 재생·일시정지하며 입력 필드나 메뉴의 키보드 조작을 가로채지 않습니다.

## 플레이어 단축키 설정

설정 → 조작에서 현재 프로필·기기의 단축키를 바꿉니다. 기능 이름 옆 키 버튼을 선택한 뒤 문자·기호·위아래 방향키 하나 또는 Shift 조합을 누르면 저장합니다. 같은 키를 여러 기능에 지정할 수 없으며 Ctrl·Alt·Command 조합은 브라우저 조작을 위해 받지 않습니다. 키보드의 물리적 위치를 사용해 한글 입력 상태에서도 같은 키가 작동합니다.

키 입력 대기 중 Esc·Tab·다른 곳 선택은 취소하고, Delete·Backspace는 해당 단축키를 해제합니다. 저장 중에는 중복 입력을 막으며 실패하면 다시 저장할 수 있습니다. 기본 단축키 복원은 현재 프로필·기기에만 적용합니다.

재생·일시정지, 앞뒤 탐색, 음량 높이기·낮추기, 전체 화면, 음소거, 다음 화, 자막 켜기·끄기, 재생 속도 높이기·낮추기, 자막 싱크 앞당기기·늦추기 등 13개 기능을 설정합니다. Space의 짧게·길게 누르기, Esc 닫기, 좌우 방향키 5초 탐색, 숫자 0–9의 재생 위치 이동은 고정입니다. 입력 필드·열린 메뉴·모달에서는 재생 단축키를 실행하지 않습니다.

아래는 실제 설정 컴포넌트를 사용하며 서버 설정은 바꾸지 않습니다.

```preview
player-shortcuts
```

## 코드 역할

`components/ui`에는 공통 조작·표현을, `features/`에는 기능별 데이터 처리를 둡니다. 페이지는 경로·권한·화면 배치를 연결합니다. 서버 API는 각 기능의 `routes.ts`, 프로필 설정은 `profiles/settings.ts`에서 연결합니다. `translation/`의 공급자별 코드는 통신 형식만 처리하고 `service.ts`는 작업 큐·캐시·키 순환·재시도를 관리합니다.
