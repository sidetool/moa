# MOA v0.1.1-beta.1

이어보기와 시청 기록을 개선하고 확장 재생 호환성을 보완한 베타입니다.

## 변경 사항

- 완료로 판정된 회차에서 나가면 홈의 이어보기에 다음 미완료 회차를 표시합니다. 다음 회차를 이미 일부 봤다면 저장된 위치에서 이어봅니다.
- 플레이어 종료 시 저장이 끝난 뒤 홈·상세·시청 기록을 갱신합니다.
- 시청 기록을 작품별로 묶어 볼 수 있습니다. 기본값은 켜짐이며, 기록 화면이나 설정에서 끌 수 있습니다. 개별 회차 기록은 그대로 보존합니다.
- 작품 단위 기록 삭제를 지원합니다. 여러 회차가 포함된 경우 확인 후 삭제하며 현재 프로필에만 적용합니다.
- 기존 확장의 Video.url로 전달되는 제한된 데이터 HLS 재생목록을 지원합니다. 새 확장 형식을 요구하지 않습니다.
- 데이터 HLS의 인증 헤더를 원본 출처로 제한하고, 영상 없음과 지원하지 않는 형식의 오류를 구분합니다.
- 실제 확장 실행부터 재생 세션 생성까지의 통합 검사와 이어보기·기록 회귀 검사를 PR 및 릴리스 빌드에 추가했습니다.

## 업데이트 및 범위

- 릴리스 설치에서는 업데이트 채널을 **베타**로 선택해 확인·설치할 수 있습니다. 정식 채널의 최신 버전은 v0.1.0으로 유지됩니다. 자동 설치는 없습니다.
- v0.1.0과 DB 테이블 구조는 같습니다. 업데이트 전 기존 백업·상태 확인 절차를 사용합니다.
- 데이터 HLS는 유한 길이의 media playlist에 한정됩니다. 자세한 범위는 [호환성 안내](https://github.com/sidetool/moa/blob/v0.1.1-beta.1/docs/PLAYBACK.md#인라인-hls)를 참고하세요. Mangayomi 앱 자체나 모든 모바일·TV 플레이어에서의 호환성을 보장하는 변경은 아닙니다.
- 모바일 PiP 자막과 TV 인증 방식은 이번 버전에서 변경하지 않았습니다.
- 브라우저 인증은 계속 선택 기능입니다. 사이트별 확장·사용자 데이터는 릴리스에 포함하지 않습니다.
