# MOA v0.1.2

이전 정식 **v0.1.1 이후의 전체 변경**입니다. beta.1~4와 이후 재생 수정, 다른 기여자의 재생·설정 개선을 포함합니다.

## 추천·홈·검색

- 시청 기록과 내 목록을 바탕으로 최대 40개 작품을 추천합니다. 관심 없음·되돌리기·숨긴 추천 초기화를 지원합니다.
- 애니 추천이 부족할 때만 AniList로 보강할 수 있습니다. 기본은 꺼짐이며 TMDB 연결과 기존 작품 ID를 유지합니다.
- 오늘의 TOP 10은 현재 홈 탭에 설정한 소스의 인기 순위를 합산하고 같은 작품의 중복 득표를 제외합니다. 실제 일일 시청 통계는 아닙니다.
- 홈에서 선택하지 않은 소스의 작품도 볼 목록에 표시합니다. 작품 묶기 상태의 이어보기는 실제로 보던 회차·위치를 유지합니다.
- 원제·다른 제목·연결된 TMDB 작품을 활용한 검색과 작품 묶기 후보 검색을 개선하고, 홈에서 불필요한 작품 정보 처리를 줄였습니다.
- 소스 목록 미리 불러오기·중지를 추가하고 필터·정렬, 언어·상태 표시와 소스 관리 화면을 정리했습니다. 목록 저장은 영상 다운로드와 별개입니다.

## 서버 다운로드

- 회차를 누르면 설정한 화질로 바로 저장합니다. 현재 시즌 전체 다운로드는 이미 받았거나 진행 중인 회차를 제외합니다.
- 진행 상태·용량·오류를 표시하고, 작품별 묶기·접기, 더 보기, 선택 삭제·취소·재시도를 지원합니다. 재생 중인 저장본은 삭제하지 않습니다.
- 완료된 저장본은 원래 회차의 시청기록으로 재생하며 원본 소스로 전환할 수 있습니다. 일부 자막 저장 실패는 영상 저장 완료와 구분합니다.
- 대기 중인 작업은 재시작 후 이어서 처리합니다. 진행 중 끊긴 작업은 직접 재시도하며 대기열은 최대 500개입니다.
- HLS 조각을 제한된 수로 병렬 수신합니다. 실제 속도는 소스와 네트워크에 따라 달라집니다.
- 기본은 꺼짐입니다. 저장 공간과 한도를 준비하고 켜야 다운로드 UI가 나타나며, 꺼도 기존 저장본과 기록은 유지합니다.

## 재생·자막·번역

- 영화·드라마 구간 건너뛰기를 추가했습니다. 영상 길이에 맞는 판본이 확인될 때만 제공하며 기존 AniSkip을 유지합니다.
- 재생 바에서 장면 미리보기를 제공합니다. 지원하지 않는 영상에서는 기존 탐색을 사용합니다.
- ‘처음부터 보기’가 영상 준비 전에도 0초를 적용하도록 수정했습니다. 안내는 표시 시점부터 5초 뒤 사라지며 로딩·일시정지로 타이머가 다시 시작되지 않습니다.
- 모바일에서 조작 버튼이 보일 때 로딩 표시가 회전하지 않던 문제를 수정했습니다.
- 자막 선택·끄기를 프로필의 다른 기기에서도 이어 사용하고, 자막 모양·조작 설정은 기기와 프로필별로 보관합니다. 기존 설정을 가져오며 새 선택이 늦은 응답으로 덮이지 않도록 했습니다.
- 자막 모양의 상세 조절·간격 선택·기본값 복원을 정리하고, 관리자가 자막 선택 기억의 보관 기간과 삭제를 관리할 수 있게 했습니다.
- 번역 키의 한도·권한·크레딧 부족을 구분하고 대기·재시도·취소 처리를 개선했습니다.

## 예고편·쇼츠 · 실험

- 재생할 수 없는 예고편은 다른 후보로 전환합니다. 선택적인 YouTube Data API로 재생 가능 여부와 지역 제한을 미리 확인합니다.
- 프로필별 쇼츠 피드와 모바일 하단 메뉴를 추가했습니다. 영화·시리즈·애니 다중 선택, 취향·인기·혼합 추천과 반복 표시 기간을 설정합니다.
- 본 작품·직접 넘긴 작품은 기본 일주일 동안 제외합니다. 재생 실패도 별도로 숨겨 같은 작품이 계속 앞에 나오지 않게 했습니다. 본편 시청기록과는 분리합니다.
- 직접 재생용 도구를 표준 앱 이미지에 포함했습니다. 다음 두 작품의 초기 영상·음성을 제한된 용량으로 미리 준비하며, 준비 실패 시 앱 안의 YouTube 재생으로 전환할 수 있습니다.
- 직접 재생에서 자막·설정에 따른 번역, 탐색 막대, 길게 눌러 2배속, 설명 펼치기와 설정 내 최대 720p 화질 선택을 지원합니다.
- 모바일은 기본 화면 채움, PC는 전체 보기이며 명시적인 OFF를 유지합니다. 모바일 핀치로 전환하고 기기별로 저장합니다. 세부 설정은 기본으로 접어 둡니다.

## 설정·계정·플러그인

- 영상 소스·라이브러리·자막 관리·계정과 초대·원격 접속을 설정 안에서 관리하도록 정리했습니다. 모바일 TMDB·YouTube 입력칸과 상태 배지 정렬도 개선했습니다.
- 로그인 기기 확인, 기기별·다른 기기 전체 로그아웃과 로그인 유지 기간 설정을 추가했습니다.
- 플러그인의 URL 설치·업데이트 확인과 저장 데이터 확인을 추가했습니다. 새 권한은 승인 후 적용합니다.
- 플러그인에 읽기 전용 시청기록·내 목록·인기·인물 정보 API를 추가하고, 기록·내 목록 날짜 필터의 시간대 처리를 수정했습니다.
- 선택 설치 ZIP 6종: **인기 작품**, **출연진·제작진**, **한국 개봉·방영 일정**, **내 목록 소식**, **국내 극장 박스오피스**, **작품 리뷰**. 박스오피스는 KOBIS 키가 필요하고 리뷰는 TMDB·AniList를 지원합니다. AniList 추천·리뷰는 요청 한도를 공유합니다.

## 설치·업데이트

- 새 Compose 설치에 웹 업데이터를 기본 연결합니다. 정식·베타 확인과 설치는 설정 → 정보에서 하며 자동·예약 설치는 없습니다.
- APK 확장·브라우저 인증은 선택 설치로 변경했습니다. 웹의 추가 기능에서 설치·다시 사용하고, 사용 중지는 접힌 관리 메뉴에서 처리합니다. 실패하면 이전 구성으로 복구합니다.
- ByeDPI를 켜면 기본 프록시로 유지하고, 끄면 이전 수동 프록시 또는 직접 연결로 돌아갑니다. 확장별 프록시가 우선합니다.
- 기존 v0.1.1 릴리스 업데이터가 빠뜨린 다운로드 저장 공간은 새 도구가 유휴 상태에서 연결합니다. 기존 경로·데이터를 유지하며 연결 과정에서 앱이 한 번 더 재시작할 수 있습니다.

## 업데이트 참고

- **v0.1.1 이상**에서 업데이트합니다. 기존 계정·설정·기록·APK 및 외부 서비스 연결은 유지합니다.
- 다운로드·쇼츠·AniList 보강·ByeDPI는 직접 켜서 사용합니다. 브라우저 인증 이미지는 AMD64 전용입니다.
- 다운로드는 서버 저장이며 기기 오프라인 저장은 아닙니다. 라이브·DASH·DRM 저장은 지원하지 않습니다. 영상 파일은 DB 백업에 포함되지 않습니다.
- 쇼츠 직접 재생·외부 스킵 정보는 영상·네트워크·판본에 따라 제공되지 않을 수 있습니다. 모바일 PiP 자막·TV 인증 개선은 이번 범위에 포함되지 않습니다.
