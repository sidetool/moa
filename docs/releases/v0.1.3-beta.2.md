# MOA v0.1.3-beta.2

다음 화 전환을 조절하고, 화질 선택과 기본 화질 적용, 다운로드를 껐을 때의 작품 화면과 기존 자막 설정 호환성을 수정했습니다.

## 다음 화 재생

- AniSkip 등으로 엔딩 구간이 확인된 영상은 기존처럼 엔딩에 맞춰 다음 화로 넘어갑니다.
- 엔딩 정보가 없는 영상에 적용하던 고정 전환 시점을 제거했습니다. 기본값은 영상이 끝난 뒤 다음 화를 재생합니다.
- 재생 고급설정에서 엔딩 정보 없는 영상의 다음 화 안내 시작 시점을 종료 전 0~600초로 지정할 수 있습니다. 0초는 영상이 끝난 뒤입니다. 기존 자동 재생 대기 시간은 별도로 적용됩니다. 예를 들어 종료 90초 전·대기 5초이면 약 85초를 남기고 넘어갑니다. 설정 시간이 영상 전체 길이 이상이면 끝난 뒤에 안내합니다.
- 엔딩 정보 없는 영상을 이어볼 때 남은 시간이 짧다는 이유만으로 즉시 다음 화로 넘어가지 않습니다.
- PC 마우스 이동뿐 아니라 모바일 화면 터치와 TV 방향키로도 카드와 카운트다운을 즉시 닫을 수 있습니다. 해당 회차가 끝나도 취소한 카운트다운은 다시 시작하지 않습니다. 조작하지 않으면 설정한 대기 시간 뒤 다음 화를 재생합니다.

## 화질

- 확장이 여러 해상도를 제공하면 재생 설정에서 화질을 선택할 수 있습니다. HLS 내부 화질은 ‘자동’도 지원하며, 재생 중인 실제 해상도를 함께 표시합니다.
- 기본 화질 설정을 새 재생에 적용합니다. 지정한 높이 이하의 가장 높은 화질을 선택하고, 없으면 가장 낮은 화질을 사용합니다. 재생 중 직접 고른 화질은 유지합니다.
- 서버 이름의 ‘HD’ 표기를 해상도로 추정하지 않습니다. 해상도 정보가 없는 소스는 기존 기본 영상을 사용합니다.
- 중간 화질 후보에서 재생을 시작해도 연결 실패 시 앞쪽 서버까지 한 번씩 시도합니다.

## 다운로드와 자막

- 서버 다운로드가 꺼졌거나 저장소가 준비되지 않았으면 작품 화면의 영화·회차·전체 회차 다운로드 버튼과 설정 유도 링크를 숨깁니다. 설정 변경은 새로고침 없이 반영합니다.
- ‘ASS 원본 효과 유지’는 직접 켰을 때만 적용합니다. 새 설정값이 없는 기존 기기의 자막 크기·그림자·외곽선 설정을 유지하고, 명시적으로 켜거나 끈 선택도 보존합니다.

## 업데이트

설정 → 정보에서 사전 릴리스 채널을 선택해 업데이트합니다. 새 전환 시점은 프로필별로 저장됩니다. 데이터베이스 초기화나 재설치는 필요하지 않습니다.
