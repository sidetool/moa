# 계정과 프로필

인증 서버는 계정과 로그인 세션을 관리합니다. 최초 관리자는 [배포 안내](DEPLOYMENT.md#새-설치)에 따라 웹 설정 화면에서 만듭니다. 기존 관리자의 비밀번호는 [복구 명령](DEPLOYMENT.md#관리자-비밀번호-복구)으로 재설정합니다. 관리자 화면에서 초대를 발급하고 계정 상태를 관리할 수 있습니다.

계정은 접근 권한을 구분하며, 계정 안의 프로필은 시청 기록·찜·개인 설정을 나눕니다. 다른 계정의 프로필이나 재생 세션에는 관리자도 접근할 수 없습니다. 카탈로그와 다운로드 캐시는 공유합니다. 전역 소스·라이브러리·자막 삭제·번역 설정은 관리자 전용입니다.

게이트웨이는 요청자가 보낸 계정 헤더를 제거하고 인증 결과로 덮어씁니다. 앱 포트와 인증 서버는 외부 클라이언트가 우회 접근할 수 없어야 합니다. 계정 DB·초기 인증 정보·CSRF 비밀 값·초대와 세션 토큰은 비공개 자료입니다. HTTPS 주소에서는 Secure 쿠키를 사용합니다.

백업에는 앱 DB와 인증 DB를 함께 포함합니다. 계정·프로필의 DB 연결 관계와 APK 데이터가 연관되므로 선택한 테이블만 복사하는 방식으로 이관하지 않습니다. [보안 제보](../SECURITY.md)를 참고합니다.

## 어린이 프로필

키즈 프로필은 승인된 TMDB 연결의 관람 등급을 사용하며 서비스 내부의 12세 이하 정책으로 필터링합니다. 성인 표시와 높은 등급은 차단합니다. 알 수 없는 등급·미연결 정보는 보수적으로 처리합니다. 등급이 비어 있고 Family/Kids 장르가 확인된 경우 예외적으로 허용하며 Animation 장르만으로 허용하지 않습니다.

이 정책은 국가별 법적 등급의 동등성이나 연령 적합성을 보장하지 않습니다. 원격 메타데이터 오류·미분류·소스의 잘못된 종류가 결과에 영향을 줄 수 있습니다. 보호자는 허용 소스와 연결 메타데이터를 직접 확인합니다. 카탈로그·검색·상세·시즌·재생 요청에 정책을 적용하며 계정 간 격리는 위 계정 정책을 따릅니다.
