# 스타일 규칙

영상 중심의 어두운 화면을 유지합니다. 관련 항목은 간격과 밝기 차이로 구분하고 설정의 이름·값·보조 버튼을 맞춥니다. 실제 값은 `apps/web/src/styles/_tokens.scss`를 기준으로 합니다.

## 레이아웃

페이지 여백은 `clamp(16px, 4vw, 56px)`입니다. 작은 화면에서는 `min-width: 0`과 줄바꿈으로 가로 넘침을 막습니다. 모달은 화면 가운데에 두고 최대 480px, 양옆 16px 여백, 내부 스크롤을 사용합니다. 플레이어와 탐색은 기기의 안전 영역을 유지합니다.

문서 화면은 최대 1200px, 읽기 폭 80ch, 목차 폭 220px입니다. 760px 이하에서는 목차를 접습니다.

## 글자와 색상

Pretendard Variable과 시스템 한글 글꼴을 사용합니다. 본문은 1rem·줄높이 1.6, 보조 글자는 .875rem, 조작 요소는 .95rem·줄높이 1.4, 섹션 제목은 1.2rem입니다. 화면 확대 시 고정 높이로 글자를 자르지 않습니다.

흰 버튼에는 어두운 글자를, 어두운 표면에는 `--text`·`--text-2`를 사용합니다. 오류는 색상과 설명을 함께, 선택은 체크와 접근성 상태를 함께 표시합니다. 일반 글자 대비는 WCAG 2.2 AA의 4.5:1을 검사 기준으로 합니다.

## 크기와 포커스

버튼·입력·`Select`의 최소 높이는 40px, 큰 버튼은 48px, 선택 버튼은 34px입니다. 포커스는 밝은 2px 테두리와 2px 간격을 사용하며 원래 모양을 유지합니다. 비밀번호 표시 버튼과 부모의 `overflow`가 포커스 테두리를 자르지 않게 합니다. TV 탐색은 3px 테두리와 넓은 스크롤 여백을 유지하고 강제 색상 모드는 시스템 색상을 따릅니다.

## 간격과 표면

간격은 4·8·12·16·20·24·32·40·48px 중 용도에 맞는 값을 사용합니다. 관련 요소는 8–12px, 폼 행은 16–24px, 섹션은 32–48px로 구분합니다. 테두리는 1px, 모서리는 6·10·14px입니다. 그림자는 팝업·모달에 사용합니다. 드롭다운은 목록 여백 5px, 항목 여백 위아래 9px·좌우 10px을 유지합니다.

## 아이콘과 애니메이션

`lucide-react`를 사용합니다. 장식 아이콘에는 `aria-hidden`, 아이콘 버튼에는 접근 가능한 이름을 지정합니다. 드롭다운 화살표는 축소하지 않고 오른쪽 가운데에 두며 글자와 최소 8px 간격을 유지합니다.

선택 배경은 .3초, 메뉴는 .24초 동안 전환합니다. 로딩 외의 자동 움직임을 추가하지 않으며 `prefers-reduced-motion`에서는 이동과 전환을 최소화합니다.

## 공통 스타일 값

같은 수치여도 용도가 다른 변수는 구분합니다. 전체 목록과 변경은 `_tokens.scss`에서 관리합니다.

- 강조: `--accent: #7b61ff`, `--accent-strong: #9884ff`입니다.
- 배경: `--bg: #09090b`, `--bg-raised: #111114`입니다.
- 표면: `--surface-1: #17171b`, `--surface-2: #202025`, `--surface-3: #2a2a30`입니다.
- 글자: `--text: #f5f5f7`, `--text-2: #c7c7cf`, `--text-3: #8e8e99`입니다.
- 상태: `--success: #3fcf8e`, `--warning: #f5b84b`, `--danger: #ff5a6a`입니다.
- 전환: `--motion-fast: .15s`, `--motion-normal: .24s`, `--motion-slow: .3s`입니다.

`--selected`와 `--segments`는 `SegmentedControl`이 선택 위치와 항목 수에 맞춰 제공합니다. 문서 전용 `--docs-*` 값은 `apps/web/design-system/_document.scss`에서 관리합니다. `--docs-header-offset`은 실제 헤더 높이에 맞춰 갱신하며 투명도를 줄이는 환경에서는 불투명 배경을 사용합니다.
