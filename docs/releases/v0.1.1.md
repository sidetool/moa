# MOA v0.1.1

이어보기·시청 기록, 확장 주소 변경 대응과 자막·설정 화면을 개선한 정식 릴리스입니다. v0.1.1-beta.1~3의 변경과 AniSkip 구간 표시 수정을 포함합니다.

## 주요 변경

- 완료한 회차 다음에 볼 회차를 홈의 이어보기에 표시합니다. 이미 일부 시청한 다음 회차는 저장된 위치에서 이어봅니다.
- 시청 기록을 작품별로 묶어 볼 수 있습니다. 기본값은 켜짐이며 기록 화면·설정에서 끌 수 있습니다. 개별 회차 기록은 유지됩니다.
- 확장 업데이트로 확인된 사이트 주소 변경을 기존 작품·회차의 별칭으로 연결해 시청 기록과 이어보기 위치를 보존합니다. 기존 Mangayomi JS·Aniyomi APK 형식을 유지합니다.
- 제한된 데이터 HLS 재생목록을 지원하고, 인증 헤더를 원래 출처에 한정합니다.
- 프로필별 자막 선택을 서버에 저장하고 묶인 작품의 같은 회차에 재사용합니다. 기존 브라우저의 선택은 서버 선택을 덮어쓰지 않도록 이전합니다.
- 자막 관리, 회원별 시청·자막 추가·번역 권한과 자막 모양 미리보기·슬라이더를 추가했습니다. 설정 화면을 작업별로 정리했습니다.
- 일반 회원도 활성화된 HTML 플러그인을 실행할 수 있습니다. 설치·삭제 등 플러그인 관리는 관리자 전용입니다.
- 영상 길이가 갱신되어 AniSkip을 다시 조회할 때, 부분 응답이나 조회 실패로 이미 확인한 오프닝 구간이 지워지던 문제를 수정했습니다. 다른 재생 세션으로 기존 구간을 넘기지 않습니다.

## 업데이트

- 정식·베타 채널 모두에서 이 버전을 확인하고 웹에서 직접 설치할 수 있습니다. 자동 설치는 하지 않습니다.
- v0.1.0에서 후보 코드로 직접 업그레이드하고 이전 이미지로 복구하는 격리 검사를 통과했습니다. 프로필·시청 위치·관심 목록·설정·인증 세션과 DB 무결성을 확인했습니다.
- 기존 기록을 보존하고 주소 별칭·자막 저장용 테이블 및 계정 권한 열을 추가합니다. 설치 전 업데이터가 백업하며, 새 기능을 사용한 뒤 임의로 구버전으로 내리는 것은 권장하지 않습니다.
- AniSkip은 현재 영상 길이에 맞는 등록 구간이 있는 경우에만 표시됩니다. 모바일 PiP 자막과 쿠키를 보관하지 못하는 TV의 인증 방식은 이번 변경에 포함되지 않습니다.
- 브라우저 인증은 선택 기능입니다. 사이트별 비공개 확장과 사용자 데이터는 배포에 포함하지 않습니다.
