# MOA v0.1.2-beta.4

기본 설치를 가볍게 만들고, 필요한 추가 기능을 웹 설정에서 설치하도록 개선했습니다. 정식 채널과 기본 설치 안내는 v0.1.1을 유지합니다.

## 주요 변경

- **추가 기능 관리**: 릴리스 업데이터가 연결된 서버에서는 설정 → 정보 → 추가 기능에서 APK 확장과 브라우저 인증을 설치하거나 다시 사용할 수 있습니다. 사용 중지는 접힌 관리 메뉴에 있으며 데이터와 이미지는 남습니다. 적용 실패 시 이전 구성으로 복구합니다.
- **가벼운 새 설치**: APK 확장과 브라우저 인증은 선택 설치로 바뀝니다. 기존 설치의 연결과 사용 설정은 유지합니다. 브라우저 인증 이미지는 현재 AMD64만 지원합니다.
- **ByeDPI 우회**: 네트워크 설정에서 켜면 기본 프록시로 사용하고, 끄면 저장해 둔 수동 프록시 또는 직접 연결로 돌아갑니다. 확장별 프록시가 우선하며 기본값은 꺼짐입니다. 기존 Compose를 유지한 업데이트에서도 보조 컨테이너가 연결할 수 있도록 했습니다.
- **쇼츠·다운로드 준비**: 표준 앱 이미지에 직접 재생용 추출 도구를 포함하고, 새 설치에 서버 다운로드 저장 공간을 연결합니다. 다운로드는 한도를 정하고 직접 켜야 사용됩니다. 기존 쇼츠 설정과 명시적인 비활성화 설정은 유지합니다.
- **모바일 설정 정리**: TMDB·YouTube 상태 배지와 입력칸 정렬을 개선하고, 좁은 화면에서 설명이 지나치게 줄바꿈되는 문제를 줄였습니다.

## 업데이트 참고

- 추가 기능 관리는 이번 릴리스의 호스트 업데이터가 적용된 뒤 사용할 수 있습니다. 수동·외부 연결은 자동으로 변경하지 않습니다.
- 기능 설치·사용 중지 중에는 잠시 재시작할 수 있습니다. 시청기록과 기존 저장본은 유지합니다.
- 직접 재생과 우회 기능은 사이트·영상·네트워크에 따라 실패할 수 있습니다. 개인 소스 확장이나 사이트별 데이터는 포함하지 않습니다.
