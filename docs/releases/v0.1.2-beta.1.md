# MOA v0.1.2-beta.1

시청기록 기반 추천, 영화·드라마 구간 건너뛰기, 소스 영상 서버 저장과 플러그인 API를 추가한 베타입니다. 정식 채널은 v0.1.1을 유지합니다.

## 주요 변경

- 최근 시청기록과 확인된 TMDB 작품 정보를 활용한 개인 추천을 홈에 표시합니다. 관심 없음·되돌리기·숨긴 추천 초기화와 표시 설정을 제공합니다. 기록은 마지막 시청 위치를 사용하며 누적 시청시간 통계는 아닙니다.
- 영화·드라마에도 TheIntroDB의 확인 가능한 오프닝·크레딧 구간을 제공합니다. 영상 길이에 맞는 단일 판본이 있을 때만 사용하며, 정보가 없는 작품은 기존처럼 재생됩니다. 기존 AniSkip과 마커를 유지하고 새 크레딧 때문에 자동으로 다음 회차로 이동하지 않습니다.
- 관리자에게 소스 영상의 서버 저장 기능을 제공합니다. 유한 MP4·일반 HLS와 AES-128을 지원하며 완료된 저장본은 같은 회차와 시청기록으로 재생합니다. 원본 소스 재생도 선택할 수 있습니다.
- 저장 목록을 작품별로 묶고 접을 수 있습니다. 선택 삭제·진행 표시·취소·재시도를 제공하며, 재생 중인 저장본은 삭제하지 않습니다. 일부 삭제가 실패하면 해당 항목과 이유를 남깁니다.
- 플러그인에 명시적 권한을 가진 읽기 전용 시청기록(`history.read`), 인기 목록(`discovery.read`), 인물 정보(`metadata.read`) API를 추가했습니다. 기존 플러그인에 새 권한을 자동 부여하지 않습니다.

## 선택 설치 플러그인

아래 ZIP을 다운로드해 설정의 플러그인 설치에서 선택하세요. MOA v0.1.2-beta.1 이상과 서버의 TMDB 설정이 필요합니다. 별도 설치하지 않으면 기존 화면을 유지합니다.

- **trending-titles-0.1.0.zip**: 홈에서 영화·TV의 일간·주간 인기 목록을 보고 MOA에서 검색합니다.
- **title-people-0.1.0.zip**: 기존 작품 화면에서 전체 출연진·제작진과 인물의 다른 참여 작품을 봅니다. 연결된 TMDB 정보를 사용하며, TV 정보는 시리즈 전체 기준입니다. 더빙 언어를 별도로 판별하지 않습니다.

## 서버 저장 설정과 제한

- 서버 저장은 MOA에 접속해 보는 기능입니다. 기기 오프라인 저장이나 PWA는 아닙니다.
- `/data`와 분리된 쓰기 가능한 `/downloads` 저장소와 관리자 용량 설정이 필요합니다. 설정 전에는 파일을 자동으로 받지 않습니다.
- 기존 릴리스 설치의 이전 업데이터는 새 저장 마운트를 추가하지 않을 수 있습니다. 저장 기능이 미설정으로 표시되면 [서버 저장 안내](https://github.com/sidetool/moa/blob/v0.1.2-beta.1/docs/SERVER-SAVES.md)에 따라 마운트와 `MOA_DOWNLOAD_ROOT`를 한 번 설정하세요. 기존 시청에는 필요하지 않습니다.
- 라이브·DASH·DRM 및 일부 특수 스트림은 저장을 지원하지 않습니다. 저장 미지원과 기존 재생 지원은 별개입니다. 일부 자막 저장 실패는 영상 저장 완료와 구분해 표시합니다.
- 업데이트·재시작으로 중단된 저장은 직접 재시도합니다. 영상은 DB 백업에 포함되지 않으며, 저장본 삭제는 시청기록을 지우지 않습니다.

## 업데이트와 검증 범위

- v0.1.1 이상에서 베타 채널로 확인·수동 설치합니다. 정식 사용자에게 베타를 자동 설치하지 않습니다.
- 공개 v0.1.1 이미지와 후보 코드를 임시 DB에 순서대로 적용·복구·재적용하여 설정·기록·관심 목록, 실제 MP4 Range 재생과 DB 무결성을 확인했습니다.
- 관련 API·권한·키즈 제한·저장 수명 테스트, 실제 FFmpeg 합성 미디어 처리, 모바일·데스크톱 UI와 플러그인 SDK 검사를 수행했습니다.
- 장편 저장 안정성과 작품별 외부 스킵 구간 정확도는 베타에서 확인할 범위입니다. 모든 소스·판본의 동작을 보장하지 않습니다.
- 구버전으로 돌아가면 새 기능과 저장본 재생을 사용할 수 없습니다. 저장 볼륨을 삭제하지 마세요. 업데이트 실패 시 복구와 새 기능을 사용한 뒤 임의로 다운그레이드하는 것은 다릅니다.
- 모바일 PiP 자막, TV 인증 개선과 시청시간 통계는 포함하지 않습니다. 비공개 확장·사용자 데이터는 릴리스에 포함하지 않습니다.
