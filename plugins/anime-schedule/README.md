# 요일별 신작

홈에 한국 시간 기준 애니메이션 편성표를 표시합니다. 오늘 요일을 먼저 보여 주며 요일·방영 시간·결방·첫 방송 예정일을 확인할 수 있습니다. 방영 종료일이 지난 작품은 제외합니다.

큰 포스터 아래에 방영 시간과 제목을 표시합니다. 화살표 버튼은 포스터 높이에 맞춰 목록 양끝에 붙이며 안쪽 모서리만 둥글게 표시합니다. 마우스를 목록에 올리거나 키보드로 버튼을 선택하면 나타나고, 터치 화면에서는 항상 표시합니다. 마우스가 목록을 벗어나거나 더 이동할 페이지가 없으면 버튼이 부드럽게 사라집니다. 원형 요일 버튼은 왼쪽에 모아 표시하며, 화면이 좁아지면 4개·3개 두 줄로 배치해 버튼 크기를 유지합니다.

홈을 열면 오늘의 편성표를 먼저 표시하고 모든 요일의 작품 정보와 포스터를 미리 불러옵니다. 최대 3개 요청을 병렬로 처리하며 같은 작품과 이미지는 다시 내려받지 않습니다. 이미지가 준비되는 동안 같은 크기의 스켈레톤을 표시합니다.

서버의 TMDB 연결로 작품 포스터를 표시합니다. MOA에 저장된 작품과 정확히 일치하면 상세 페이지로 이동하고, 없거나 구분하기 어려우면 제목을 검색합니다. 아직 불러오지 않은 소스의 작품 목록은 조회하지 않습니다.

요일을 바꿔도 이미 불러온 결과를 재사용하며, 새로고침하면 전체 요일을 다시 조회합니다. 포스터는 서버 이미지 캐시가 유효하면 TMDB에서 다시 내려받지 않습니다. 캐시는 서버를 다시 시작해도 유지되며, 30일이 지나거나 용량 정리로 삭제되면 다시 가져옵니다. 방향키·Home·End로 요일을 바꿀 수 있습니다. TMDB 연결이 없거나 이미지 조회에 실패해도 편성표와 작품 이동은 사용할 수 있습니다.

## 설치와 권한

1.3.6은 MOA 0.1.2 이상과 `moa.metadata.lookup()`을 지원하는 서버가 필요합니다. 더 작은 동시 요청 한도를 사용하는 서버에서 `plugin-busy`가 발생하면 요청을 하나씩 처리하고 실패한 요청을 한 번만 다시 시도합니다. 관리자가 폴더를 설치하거나 다음 명령으로 ZIP을 만듭니다.

포스터 캐시를 사용하려면 플러그인과 함께 MOA 서버도 업데이트해 주세요. 기존 서버에서도 플러그인은 동작하지만 새로고침한 이미지는 다시 내려받습니다.

```sh
node plugins/template/build.mjs ../anime-schedule
```

생성 파일은 `plugins/template/dist/anime-schedule.zip`입니다. 설치 방법은 [플러그인 안내](../../docs/PLUGINS.md)를 참고해 주세요.

| 권한 | 용도 |
| --- | --- |
| `app.navigate` | 작품 상세 또는 검색으로 이동합니다. |
| `metadata.read` | 포스터와 일치하는 MOA 작품을 조회합니다. |
| `ui` | 홈 패널 높이를 조절합니다. |
| `https://api.anissia.net` | 편성표를 조회합니다. |
| `https://image.tmdb.org` | TMDB 포스터를 내려받습니다. |

## 출처

[Anissia](https://anissia.net)의 [공개 편성표 API](https://github.com/anissia-net/document/blob/main/api_anime_schdule.md)를 사용합니다. 일정은 영상 소스의 업로드 시각이나 재생 가능 여부와 다를 수 있습니다. TMDB API 키·계정 정보·영상 주소는 플러그인에 전달하지 않습니다. 어린이 프로필에서는 작품 정보 조회가 제한됩니다.

화면의 출처 안내는 MOA 정보 페이지에서 확인할 수 있습니다. 포스터 출처는 [TMDB](https://www.themoviedb.org/)이며 TMDB의 승인이나 인증을 받은 제품은 아닙니다.
