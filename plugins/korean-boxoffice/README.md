# 국내 박스오피스

MOA 홈에서 영화진흥위원회 영화관입장권 통합전산망(KOBIS) 기준 국내 극장 관객 수 순위 1~10위를 보여줍니다. 일간/주간을 선택할 수 있고, 항목을 누르면 MOA 검색(`/search?q=<제목>`)으로 이동합니다. 자동 재생은 하지 않습니다.

## 설치 조건

MOA 0.1.2-beta.3 이상의 `moa.discovery.boxOffice` SDK와 `boxoffice.read` 권한을 포함한 MOA가 필요합니다. 이전 버전에는 ZIP만 설치해도 동작하지 않습니다. 키즈 프로필에서는 제공하지 않습니다.

## 운영자 설정 (KOBIS 키)

플러그인에는 키 입력 화면이 없고 브라우저에 키를 보관하지 않습니다. 키가 없으면 일반 사용자에게는 "관리자 설정 후 이용할 수 있어요"만 표시하며, 대체 순위나 가짜 데이터를 보여주지 않습니다.

1. 영화진흥위원회 KOBIS 오픈API(https://www.kobis.or.kr/kobisopenapi/)에서 회원 가입 후 키를 발급받습니다.
2. MOA 서버 환경변수 `MOA_KOBIS_API_KEY`에 키를 설정합니다(compose 사용 시 `.env`). 자세한 내용은 `docs/PLUGINS.md`를 참고하세요.
3. MOA 서버를 다시 시작합니다. 키는 서버에서만 사용됩니다.

## 데이터 범위

- 일간: 한국 시간 기준 **어제** 하루. 주간: 지난 **완료된 월~일** 한 주.
- 국내 극장에서 상영된 한국·외국 영화 전체의 관객 수 순위이며 OTT 시청 순위가 아닙니다.
- 관객 수, 누적 관객 수, 전 기간 대비 순위 변화(▲ 상승, ▼ 하락, – 변동 없음, NEW 신규 진입)를 표시합니다.
- MOA 검색은 같은 제목을 찾는 것일 뿐, 해당 영화가 MOA에 있다는 뜻은 아닙니다.
- 서버 캐시는 30분, 실패 응답은 60초간 재사용합니다. 관객 수는 집계 시점 기준이며 이후 바뀔 수 있습니다.
- 플러그인에는 이전 조회 결과를 재사용하는 클라이언트 캐시가 없습니다. 기간 전환·새로 고침 시 이전 순위를 즉시 지우고, 늦게 도착한 이전 응답과 실패·미설정 응답 시에도 이전 순위를 남기지 않습니다.

## 권한

`boxoffice.read`(순위 조회), `app.navigate`(MOA 검색 이동), `ui`(홈 패널 높이 조절). 외부 연결 권한(`connect`)은 없으며 KOBIS 요청은 서버에서만 수행합니다.

## 출처

자료: 영화진흥위원회 영화관입장권 통합전산망(KOBIS) 오픈API. 화면 하단에 출처를 표시합니다.

## 빌드와 검사

저장소 루트에서:

```sh
node plugins/template/build.mjs ../korean-boxoffice
# Playwright 및 Chromium 경로를 환경변수(MOA_PLAYWRIGHT_PATH, MOA_BROWSER_EXECUTABLE)로 지정
pnpm --filter @moa/server exec tsx scripts/verify-news-boxoffice.mts
```

실제 KOBIS 키로는 검증하지 않았습니다. 공식 문서 기준 응답 형식의 합성 데이터로 서버·SDK·화면을 검사합니다.
