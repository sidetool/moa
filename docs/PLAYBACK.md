# 재생·자막·영상 저장

영상 재생과 자막, TV 연결, 서버 저장의 설정과 제한을 안내합니다.

## 키보드와 길게 누르기

설정 → 조작에서 재생 단축키를 바꿀 수 있습니다. 기능 옆 키 버튼을 선택한 뒤 문자·기호·↑·↓ 키 또는 Shift 조합을 누릅니다. 중복 키와 Ctrl·Alt·Command 조합은 사용할 수 없습니다. Esc는 입력 취소, Delete·Backspace는 단축키 해제이며 기본 단축키로 복원할 수 있습니다. 변경은 현재 프로필과 기기에 저장됩니다.

| 기능 | 기본 키 |
| --- | --- |
| 재생·일시정지 | K |
| 설정한 간격 뒤로·앞으로 | J / L |
| 음량 높이기·낮추기 | ↑ / ↓ |
| 전체 화면 / 음소거 | F / M |
| 다음 화 / 자막 켜기·끄기 | N / C |
| 재생 속도 낮추기·높이기 | Shift + , / Shift + . |
| 자막 0.5초 앞당기기·늦추기 | [ / ] |

Space 재생·일시정지, Esc 닫기, ←/→ 5초 탐색, 숫자 0–9의 재생 위치 이동은 고정입니다. 한글 입력 상태에서도 키의 물리적 위치를 사용합니다. 입력 필드·열린 메뉴·모달에서는 재생 단축키를 실행하지 않습니다.

재생 중 영상 화면이나 Space를 450ms 이상 누르면 **길게 누르기 배속**을 적용합니다. 누른 상태에서 마우스를 움직여도 유지하며 놓거나 창이 비활성화되면 원래 속도로 돌아갑니다. Space를 짧게 누르면 재생·일시정지만 전환합니다. 배속 안내는 화면 위쪽에 표시됩니다.

## 자막, 번역과 스킵

### 표시와 저장

‘ASS 원본 효과 유지’는 직접 켰을 때만 적용하며, 설정값이 없는 기존 기기는 저장한 자막 크기·그림자·외곽선을 계속 사용합니다. 이미 켜거나 끈 선택은 업데이트 후에도 유지합니다.

로컬 파일·확장 자막·온라인 후보를 선택할 수 있습니다. ASS는 JASSUB, VTT와 변환된 SRT/SMI는 브라우저 자막으로 표시합니다. 자막 높이·싱크·선택은 기기·세션 정책에 따라 보존합니다. 제목·시즌·회차와 제작자 정보를 이용해 후보를 찾지만 판본·편집·통합 회차의 일치를 보장하지 않습니다. 사용자가 확인하고 선택합니다.

수집한 자막·번역·마커·메타데이터 캐시는 앱 데이터입니다. 소프트웨어의 GPL 라이선스가 그 콘텐츠나 외부 API 데이터의 재배포 권한을 부여하지 않습니다.

### 온라인 검색과 재사용

온라인 검색은 Anissia/AniList 메타데이터, 자막 제작자 페이지의 수집 어댑터와 Jimaku를 사용할 수 있습니다. 이는 확장 저장소의 기본 등록과 별개이며 외부 네트워크 조회·파일 다운로드를 수행할 수 있습니다. 첨부 파일은 크기·경로·ZIP 항목·타임아웃을 제한합니다. 공개 URL은 재배포·번역 허가를 뜻하지 않습니다.

기본 한국어 자막 검색은 현재 회차 또는 작품 묶기의 같은 시즌·회차에 저장된 온라인 자막이 있으면 외부 조회 없이 재사용합니다. 사용자가 다시 찾기를 누르거나 검색어를 수정하면 제작자 검색을 다시 수행하며 기존 24시간 수집 캐시도 사용합니다. `/api/episodes/:id/subtitles/online?refresh=true`는 수동 재검색에 해당합니다. 다시 적용한 내용이 같은 제작자·형식·본문이면 묶인 회차의 기존 저장본을 반환하고 복사본을 만들지 않습니다. 수정된 자막 본문은 새 저장본으로 취급합니다.

등록된 제작자·아카이브에서 자막을 찾지 못하면 네이버 블로그 검색에 작품 제목·시즌·회차 검색어를 전송해 공개 블로그 글을 찾습니다. 누적 회차가 있는 작품은 회차를 생략해 검색합니다. 검색은 최대 두 번, 글 확인은 최대 네 개이며 기존 전체 시간 제한 안에서 수행합니다. 발견한 글과 첨부에도 제목·시즌·회차 검사를 적용합니다.

제작자 경로는 제목·별칭·시즌을 확인해 사용합니다. 일반 탐색에 실패하면 제한된 RSS/Atom·후속 페이지를 확인하며, 첨부 버튼의 data 속성과 스크립트 URL 문자열을 읽어도 스크립트는 실행하지 않습니다. 제작자 목록은 검색할 때마다 다시 수집하지 않으며 유지보수 시 `pnpm --filter @moa/server subtitles:directory`로 갱신합니다. 원문 출처는 `creator-directory.json`의 references에 보관합니다.

ZIP·7z·RAR·TAR에서 선택한 자막만 읽고 경로를 디스크에 풀지 않습니다. 항목 수·해제 크기·프로세스 자원·동시 디코더 수를 제한하며 암호화·링크 항목·중첩 압축은 지원하지 않습니다. 사이트 차단·시간 초과를 빈 결과와 구분하고 응답에 원시 오류나 다운로드 토큰을 넣지 않습니다. 폐쇄·삭제·비공개 게시글은 우회하지 않습니다.

검색 로직은 특정 작품의 URL이나 시즌 예외를 넣는 대신 공통 제목 정규화·시즌·회차 검사를 사용합니다. `(終)`·`[終]` 같은 완결 표기는 작품명에서 제외하되 판본과 회차 판별은 유지합니다. 이미 확인한 같은 제작자 글을 읽을 때 보관소 전체 검색을 반복하지 않습니다. 성공률은 외부 사이트 상태에 따라 달라집니다.

### 자동 싱크 맞춤

자막 고급설정에서 프로필별로 켜고 끕니다. 한국어 온라인 자막을 같은 재생 세션의 영어·일본어 자막과 비교하며, 원문의 시간을 유지하는 AI 번역 트랙은 다시 보정하지 않습니다. 기기에서 파일을 읽고 Web Worker에서 계산하므로 AI 호출·음성 인식·영상 변환은 수행하지 않습니다.

- ASS 그림·위치 지정 간판·일부 가사 스타일을 제외하고 최소 50개 대사와 5분에 걸친 증거를 요구합니다.
- ±120초의 일정한 차이만 찾습니다. 앞·중간·뒤의 시작 시각 일치율·오차·대안 후보와 차이가 충분할 때만 적용합니다. 컷 차이나 FPS 차이를 늘이거나 구간별로 변형하지 않습니다.
- 시간 패턴이 크게 다르면 자동 선택을 보류하지만 수동 선택은 가능합니다. 다른 회차인지 의미를 판별하는 기능은 아닙니다.
- 수동 싱크 조절을 우선합니다. 계산값은 현재 자막·재생 세션에만 적용하고 원본 파일·DB 본문·다른 회차에 저장하지 않습니다.
- 읽기와 계산은 5초 안에 끝내며 취소·회차 이동·자막 끄기 후 도착한 결과는 적용하지 않습니다.

반복 노래·간판이나 줄 나눔 차이로 보정할 수 없을 수 있습니다. 증거가 부족하면 기존 시각을 유지합니다.

### AI 번역

Gemini 또는 OpenAI 호환 서비스는 관리자가 키와 활성 상태를 설정한 경우 사용합니다. 자막 본문·제목·회차·문맥이 설정한 API로 전송되고 요청 비용·사용량 한도가 적용될 수 있습니다. 부분 완료·재시도·우선 구간 처리와 저장된 번역 트랙을 제공하지만 번역 품질·완료 시간을 보장하지 않습니다. 원자막과 번역을 이용할 권리는 사용자가 확인합니다.

### 구간 건너뛰기

스킵 마커는 AniSkip 조회와 로컬 시즌 오디오의 반복 구간 분석을 구분합니다. 외부 마커는 회차·길이가 맞아도 다른 판본에서 틀릴 수 있고 로컬 지문도 반복 장면을 오탐할 수 있습니다. 현재 영상에서 확인한 뒤 사용합니다. 저작권이 확인된 합성 PCM/영상으로 개발 테스트를 작성합니다.

영화·드라마는 확인된 TMDB 연결로 TheIntroDB v3를 조회합니다. 실제 영상 길이 ±2초에 맞는 단일 판본만 사용하며 미상 판본을 합치지 않습니다. 시즌·회차가 모호하거나 구간 끝이 없고 여러 구간이 섞인 결과는 적용하지 않습니다. 로컬·원격·저장본 모두 실제 재생 세션에 연결하며 기존 마커의 해당 구간을 우선합니다. 길이가 같다는 것만으로 같은 편집본을 보장하지 않습니다.

검색·압축·싱크의 유지보수 검사는 `apps/server/test/subtitles-korean`와 `apps/web/tests/subtitle-timing.test.ts`를 따릅니다. 공개 사이트 자료를 fixture로 복사하지 않고 합성 자막·영상으로 재현합니다.

## 다음 화 자동 재생

엔딩 구간 정보가 있는 회차는 해당 정보를 기준으로 다음 화를 안내합니다. 엔딩 뒤에 20초 넘게 영상이 남아 있으면 기존처럼 마지막 15초에 안내합니다. 엔딩 정보가 없는 영상은 기본적으로 끝까지 재생한 뒤 다음 화를 안내합니다.

설정 → 재생 → 모든 기기 → **재생 고급설정**에서 ‘엔딩 정보가 없을 때 다음 화 안내’를 0~600초로 바꿀 수 있습니다. 0초는 영상이 끝난 뒤이며, 설정한 시간이 영상 전체 길이 이상인 경우에도 끝난 뒤에 안내합니다. 이 값은 프로필별로 저장됩니다.

안내가 나타난 뒤에는 기존 ‘다음 화 자동 재생’과 대기 시간을 적용합니다. 예를 들어 종료 90초 전 안내·5초 대기이면 약 85초를 남기고 넘어갑니다. 종료 3초 전 안내·5초 대기이면 영상이 끝나고 약 2초 뒤 넘어갑니다. 자동 재생을 끄면 다음 화를 직접 선택해야 합니다.

카운트다운은 PC의 마우스 이동, 모바일 화면 터치, TV 리모컨 방향키로 취소할 수 있습니다. 취소 후에도 다음 화 버튼을 직접 누를 수 있습니다. 엔딩 정보 없는 영상을 이어볼 때는 남은 시간이 짧아도 즉시 건너뛰지 않습니다.

## TV 스트리밍

플레이어의 **TV 스트리밍** 버튼에서 Chromecast 또는 AirPlay로 현재 영상을 재생할 수 있습니다.

### 연결

TV와 브라우저가 같은 네트워크에 있고 TV에서 MOA 서버에 접근할 수 있어야 합니다. `localhost`와 `127.0.0.1` 주소는 TV에서 접근할 수 없으므로 서버의 LAN IP 또는 HTTPS 주소로 접속하세요. 방화벽과 리버스 프록시도 해당 주소의 접근을 허용해야 합니다.

- Chromecast: 데스크톱 Chrome에서 HTTPS 주소로 MOA에 접속하고 **Chromecast 연결**을 선택합니다. Google의 기본 미디어 수신기를 사용하며 별도의 수신기 앱 등록이 필요하지 않습니다.
- AirPlay: Safari에서 **AirPlay 준비**를 선택한 뒤 **AirPlay 기기 선택**에서 TV를 선택합니다. 영상은 현재 위치를 유지하면서 Safari의 네이티브 재생으로 전환됩니다.
- Chromecast 연결 후 모달에서 재생·일시정지, 위치 탐색, 볼륨을 조절할 수 있습니다. **연결 종료**를 누르면 전송을 중지합니다. 다시 전송하려면 연결 버튼을 선택합니다.

현재 선택한 1MB 이하의 자막을 WebVTT로 변환하여 싱크와 함께 전송합니다. AI 번역 자막과 가져온 자막도 지원합니다. ASS 배치·글꼴·효과는 TV의 기본 자막 모양으로 표시되고, 진행 중인 번역은 연결 시점까지 완성된 내용만 전송됩니다. 업데이트된 번역이나 다른 자막을 전송하려면 다시 연결하세요.

영상과 음성 코덱은 TV가 지원해야 합니다. 일부 원격 소스의 코덱이나 스트리밍 방식은 수신기에서 재생되지 않을 수 있습니다. 로컬 영상은 재생 설정의 호환 재생을 사용하면 H.264 중심으로 재생 세션을 준비할 수 있습니다.

### 접근 권한과 수명

전송 URL은 로그인한 프로필이 현재 재생 세션에 대해서만 발급할 수 있습니다. URL에는 무작위 토큰이 포함되며 계정 쿠키, 비밀번호, API 키는 TV로 전달되지 않습니다. 토큰은 해당 영상과 변환한 자막에만 접근할 수 있습니다.

URL은 영상 길이에 1시간을 더한 기간 동안 유효하며 최소 1시간, 최대 6시간 후 만료됩니다. 길이를 알 수 없는 영상과 실시간 방송은 6시간 동안 유효합니다. 연결 종료, 재생 세션 종료 또는 서버 재시작 시 사용할 수 없게 됩니다. TV 재생 중에는 이 플레이어를 열어 두세요. 플레이어를 닫거나 다른 영상·소스로 이동하면 전송을 종료합니다.

게이트웨이는 `/api/cast/`의 미디어 읽기와 CORS 사전 요청만 로그인 없이 전달하고, 서버는 모든 요청에서 토큰과 세션을 검증합니다. 기존 API와 재생 URL의 로그인 요구는 유지됩니다. 전송 URL은 다른 사람에게 공유하지 마세요.

### 검증 범위

자동 검증은 프로필 간 접근 차단, 토큰 만료·취소, Range 요청, CORS, HLS 하위 경로 변환, ASS/WebVTT 자막 변환과 브라우저 송신 흐름을 검사합니다. 실제 Chromecast·AirPlay 기기의 네트워크 탐색과 코덱 호환성은 해당 TV에서 확인해야 합니다.

## TV 리모컨 조작

설정 → 이 기기 → **TV 리모컨 모드**에서 자동 / 항상 켜기 / 끄기를 선택합니다. 이 설정은 기기 브라우저에 저장됩니다. 자동 모드는 TV 브라우저를 감지하거나 탐색 화면에서 방향키를 누르면 켜지고, 일반 브라우저에서 마우스·터치를 사용하면 해제됩니다.

### 조작

- 방향키: 가까운 카드·버튼으로 이동. 가로 목록은 선택한 카드가 보이도록 스크롤합니다.
  - 위/아래는 가장 가까운 줄을 먼저 고르고 그 줄에서 정렬이 맞는 항목으로 갑니다. 고정 상단 메뉴는 페이지에 더 위쪽 항목이 없을 때만 갑니다.
  - 좌우는 같은 줄 안에서만 움직입니다. 회차 목록처럼 오른쪽에 아무것도 없으면 멈춥니다.
  - 그룹에 바깥에서 들어오면 정해진 진입점이나 현재 선택으로 갑니다: 상단 메뉴 → 현재 탭, 히어로 → 재생, 회차 구간 → 선택된 구간, 재생 조작부 → 재생/일시정지 버튼, 패널 → 현재 회차·선택된 자막.
  - 이어보기 카드의 정보 버튼은 그 카드에서 아래로 갈 때만 거칩니다. 히어로 넘김 점은 건너뜁니다.
  - 첫 화면 포커스는 늦게 렌더링되는 히어로 ‘재생’도 기다렸다가 옮깁니다(사용자가 아직 키를 누르지 않은 경우).
- 확인(Enter/Select): 선택한 항목 실행.
- 뒤로: 열린 패널의 하위 화면 → 패널 닫기 → 재생 조작부 숨기기 → 이전 화면 순서로 동작합니다. 상세에서 돌아오면 원래 카드로 선택을 복원합니다.
- 재생 중 조작부가 숨겨져 있으면 좌우는 바로 탐색 단위만큼 이동하고 재생바에 포커스를 둡니다. 위/아래·확인은 조작부만 표시합니다.
- 재생바 좌우와 빨리 감기/되감기 키는 막대에 목표 위치를 미리 보여주고, 누름이 멈춘 뒤 0.5초 후 한 번만 이동합니다. 꾹 누르면 초당 최대 8번, 1.5초 뒤부터 3배 단위로 이동합니다.
- 오프닝·엔딩 건너뛰기 버튼이 나타나면 (사용자가 다른 곳을 조작 중이 아닐 때) 포커스를 받아 확인 한 번으로 건너뜁니다. 자막 설정 슬라이더는 기본 단위로 조정합니다.
- 재생/일시정지/빨리 감기/되감기 미디어 키 지원. 다음 화로 넘어가도 전체화면을 유지합니다.
- 상세 상단의 ‘← 뒤로’는 배경·테두리 없는 회색 글자로 표시합니다. 로딩·오류 상태에서도 사용할 수 있습니다.

브라우저에 전달되는 Samsung Back(10009), LG Back(461)도 처리합니다. 실제 TV 기기 검증은 아직 하지 않았습니다. TV 브라우저가 소비해서 웹페이지에 전달하지 않는 키는 제어할 수 없습니다.

공식 키 참고: [Samsung](https://developer.samsung.com/smarttv/develop/guides/user-interaction/remote-control.html), [LG](https://webostv.developer.lge.com/develop/guides/back-button).

## 재생 복구

원격 HLS/native 영상에서 치명적 오류가 발생하면 다음 스트림 후보를 시도합니다. 응답이 멈춘 경우 재연결 안내를 제공하고 정상적인 일시정지·숨겨진 탭은 구분합니다. 다시 시도는 현재 위치로 새 세션을 만들며 LIVE는 실시간 위치로 돌아갑니다.

다른 소스 선택은 묶인 작품의 시즌·회차를 제안합니다. 사용자가 판본과 이어보기 위치를 확인해야 합니다. 판본별 길이·장면·자막은 다를 수 있으며 선택 중에는 자동 다음 화 이동을 멈춥니다.

자막 높이·싱크·끄기 설정은 재연결에도 유지합니다. VTT는 cue 위치를, ASS는 렌더링 캔버스 위치를 조정합니다. 큰 높이 이동은 효과를 화면 밖으로 밀 수 있으므로 원래 위치로 되돌릴 수 있습니다. [자막](PLAYBACK.md#자막-번역과-스킵)을 참고합니다.

## 서버에 영상 저장

저장한 영상도 MOA 서버에 연결해서 재생합니다. 기기 자체의 오프라인 기능은 아닙니다.

Compose는 읽기 전용 `/media`, 앱·업데이트 백업용 `/data`와 별도로 `/downloads`를 연결합니다. 필요하면 생성 전 `MOA_DOWNLOAD_PATH`에 호스트 절대 경로를 지정하세요. 일반 설치는 `MOA_DOWNLOAD_ROOT`에 쓰기 가능한 기존 폴더를 지정합니다. 미디어·앱 데이터 폴더를 재사용하지 마세요.

### 켜기와 중지

기본은 꺼짐입니다. 관리자가 설정 → 서버 관리 → 다운로드에서 양수 용량을 정하고 직접 켜야 합니다. 저장소 연결·용량 지정·`MOA_DOWNLOADS_ENABLED=1`만으로 켜지지 않습니다. `MOA_DOWNLOADS_ENABLED=0`은 웹에서 바꿀 수 없는 상위 제한입니다. 사용 가능한 저장소와 용량을 검사한 뒤 설정을 순서대로 저장합니다.

웹에서 끄면 실행·대기 작업을 중단하지만 저장 영상·시청 기록은 남습니다. 다시 켜도 중단 작업을 자동 재시도하지 않습니다. 환경 변수로 금지하면 대기 작업은 보류하고 실행 작업은 중단합니다. 기존 저장 영상 재생·삭제는 사용할 수 있습니다.

릴리스 업데이터는 기존 경로를 유지하며 없는 경우 전용 빈 저장소만 추가합니다. v0.1.1 도구로 갱신된 설치는 앱이 한가할 때 새 실행 환경이 연결을 마무리하고 상태 이상 시 이전 설정으로 복구합니다. 용량이나 사용 여부를 임의로 켜지 않습니다. 수동 설치는 실제 Compose에 저장소와 `MOA_DOWNLOAD_ROOT`를 연결해야 합니다.

### 다운로드

관리자가 영화·회차 다운로드 버튼을 누르면 바로 대기열에 넣습니다. 전역 화질은 기본 1080p이며 최고·1080p·720p·480p를 고릅니다. 지정 이하의 확인된 최고 해상도, 없으면 최저 해상도, 모두 미상이면 소스 기본값을 씁니다. 같은 해상도는 소스 순서를 유지하며 HLS 마스터도 같은 규칙입니다. 새 작업 생성 시 화질을 저장하므로 이후 설정 변경이 기존 대기 작업에 영향을 주지 않습니다.

전송은 한 번에 하나, 대기열은 최대 500개입니다. 기존 토큰·명시적 선택 API도 유지합니다. APK 사용 권한은 실제 실행 중 확보·갱신하고 완료·취소·실패·종료 시 해제합니다. 명시적 선택도 전송 시 다시 확보합니다. 서명 URL·쿠키는 작업에 영구 저장하지 않습니다.

지원 형식은 길이가 정해진 HTTPS MP4, 일반 HLS, 기본 음성이 있는 마스터 HLS, AES-128 HLS입니다. HLS는 코덱 복사로 묶으며 FFmpeg에는 로컬 파일만 전달합니다. 모든 외부 요청에 소스 정책과 프록시를 적용합니다. DRM/SAMPLE-AES·실시간·DASH·EDL·인라인 목록·별도 확장 음성 배열·모호한 이전 명시적 선택은 저장을 지원하지 않습니다. 일부 HLS 지시문도 명시적으로 거부합니다. 재생 지원 범위와는 다릅니다.

외부 VTT·SRT·ASS 자막은 최대 8개를 가져오며 실패해도 영상은 저장하고 경고를 표시합니다. HLS 조각 자막은 포함하지 않습니다. 용량에는 임시 파일과 묶기 작업 공간도 포함합니다. 작업당 최대 20GiB·영상 6시간, 디스크 여유 최소 512MiB를 지킵니다. 완료 파일을 자동 삭제하지 않으며 실패한 일부 파일은 수동 재시도 시 처음부터 다시 받습니다.

상태는 요청·대기·추출·전송·마무리·완료·실패를 구분합니다. MP4는 Content-Length로 크기를 표시하고 HLS 전체 크기가 불명확하면 받은 용량만 표시합니다. 임의 진행률을 만들지 않습니다.

### 저장 영상과 삭제

자동 재생은 같은 회차의 저장 파일을 먼저 사용하며 외부 소스에 요청하지 않습니다. 원본 소스 재생도 선택할 수 있습니다. 저장 파일·진행 작업이 있으면 소스의 파괴적 삭제를 막습니다. 사용하지 않는 파일 삭제는 작품·기록·찜을 보존하며 재생 중 파일은 삭제할 수 없습니다.

목록은 이름이 아닌 저장된 작품 ID로 묶습니다. 생성 시각·ID 기준 페이지 이동으로 상태 변경·경계 항목 삭제에도 다음 항목을 유지합니다. `mediaId` 필터를 지원하며 다중 선택은 불러온 항목에만 적용합니다. 각 삭제는 재생·세션 생성 상태를 다시 검사하고 일부 실패 시 해당 항목과 선택·오류를 남깁니다.

업데이트 요청은 대기열을 멈추고 실행 작업을 중단합니다. 재시작 후 실행 중이던 작업은 수동 재시도하고, 아직 시작하지 않은 대기 작업은 업데이트 작업이 끝난 뒤 이어집니다. 영상 파일은 앱 데이터 백업에 포함하지 않으므로 필요하면 별도로 백업하세요. 시작 시 확인된 미완료 폴더만 지우며 알 수 없는 완료 `job-*` 폴더는 관리자가 확인하도록 남깁니다. 저장소 연결이 사라져도 파일 정보는 유지하고 사용 불가로 표시합니다.

### 시즌 전체 다운로드

저장이 켜져 있으면 관리자가 회차 목록 상단에서 현재 시즌 전체를 저장할 수 있습니다. 확인 창은 가능한 회차를 미리 보여줍니다. 시즌 구분이 없으면 현재 작품만 포함하며 다른 시즌 연결·작품·소스를 따라가지 않습니다. 이미 저장했거나 진행 중인 회차는 제외합니다.

서버는 저장소 확인 후 트랜잭션에서 범위·가능 여부를 다시 검사합니다. 동시·반복 요청은 진행 작업을 중복 생성하지 않습니다. 모두 제외되면 `added: 0`으로 성공합니다. 500개 대기 한도를 넘는 요청은 전체 거부합니다. 시즌·회차 순으로 실행하고 같은 생성 시각은 삽입 순서로 정합니다. 화질은 한 번 저장하고 원본 주소는 실제 실행 때 구합니다.

대기열은 재시작 후 유지합니다. 저장소 없음·공간 부족·용량 초과 시 남은 대기열도 중단해 불필요한 추출을 반복하지 않습니다. 관리자와 현재 소유·잠금 해제된 프로필이 필요합니다.

- `GET /api/admin/downloads/batch?mediaId=...&season=1` → `{total, eligible, skipped}`
- `POST /api/admin/downloads/batch` 본문 `{mediaId, season?}` → `{total, added, skipped}`

GET은 미리보기이며 예약이 아닙니다. POST에서 다시 계산합니다.

## 예고편 재생

TMDB의 YouTube Trailer·Teaser 정보를 사용합니다. 일반 예고편은 다운로드하거나 YouTube 로그인 쿠키를 가져오지 않습니다. TMDB 정보가 있어도 국가별 재생·임베드 허용을 보장하지는 않습니다.

한국어·영어·일본어·언어 미지정 영상을 확인하고 한국어, 공식 영상, Trailer 순으로 우선합니다. 서로 다른 유효 ID 최대 5개를 `MediaDetail.trailers`에 넣으며 기존 `trailer`는 첫 ID로 유지합니다. 언어를 지역 재생 가능성의 근거로 사용하지 않습니다.

예전 캐시는 상세 조회 시 같은 TMDB ID 요청을 합쳐 갱신합니다. 실패하면 이전 후보를 유지하고 5분 뒤 재시도하며, 정상 빈 응답이면 오래된 후보를 지웁니다. 전체 DB 갱신·이관 없이 일반 만료 규칙을 따릅니다. 일반 후보 전환에는 YouTube API 키가 필요하지 않으며 한 사용자의 실패로 다른 사용자 후보를 차단하지 않습니다.

공식 IFrame API에서 영상별 실패가 확인되면 남은 후보를 반복 없이 시도합니다. 클라이언트 식별 오류 153·API 로딩·HTML5 오류는 모든 영상의 재생 불가로 해석하지 않습니다. 자동재생 차단은 터치를 요청하고 긴 버퍼링·일시정지·종료는 후보 전환 사유가 아닙니다. 사용자가 내부에서 다른 후보를 고를 수 있으며 모두 실패하면 실패를 안내합니다. 오류 코드만으로 특정 국가 차단을 단정하거나 외부 YouTube 링크로 복구하지 않습니다.

### 선택적 YouTube 사전 확인

관리자가 설정에서 YouTube Data API v3 키를 저장하거나 `MOA_YOUTUBE_API_KEY`를 지정할 수 있습니다. 환경 변수가 우선하며 키는 클라이언트에 반환하지 않습니다. 저장 키를 지우면 환경 키가 없는 한 일반 TMDB 후보 재생으로 돌아갑니다. Google 프로젝트에서 해당 API를 켜야 하며 TMDB 키와는 다릅니다. 저장 성공은 Google의 키 승인 확인이 아닙니다.

`GET /api/media/:id/trailers`는 기존 작품 후보만 검사하며 계정·프로필·PIN·어린이 정책을 유지합니다. 소스 조회·제목 재매칭을 하지 않습니다. 예고편을 열 때만 제한 시간 내 조회하고 키 없음·통신/인증/할당량/응답 오류·동시 한도 초과 시 원래 후보를 유지합니다.

`videos.list` 한 요청으로 기존 ID 최대 5개를 확인합니다. 삭제·비공개·임베드 금지·연령 제한 영상은 제외하고 지정 지역(기본 KR) 허용 영상을 먼저 둡니다. 지역 제한 후보는 뒤에 남기며 IP나 사용자의 실제 국가를 추측하지 않습니다. API 정보는 참고이며 실제 플레이어 결과가 우선입니다.

같은 후보·지역별로 최대 512개를 6시간 메모리에 보관합니다. 같은 요청은 합치고 동시 최대 4개·각 4초 제한, 실패 시 공통 5분 대기를 적용합니다. 설정 변경 시 캐시와 이전 조회를 취소합니다. 지역 결과로 TMDB 원본을 덮어쓰지 않습니다. 제목만으로 잘못된 시즌·리메이크·팬 영상을 고를 수 있어 YouTube 자동 검색은 하지 않습니다.

공식 안내: [플레이어 오류](https://developers.google.com/youtube/iframe_api_reference#onError), [국가 제한](https://support.google.com/youtube/answer/92571), [연령 제한](https://support.google.com/youtube/answer/2802167), [videos.list](https://developers.google.com/youtube/v3/docs/videos/list), [지역·임베드 정보](https://developers.google.com/youtube/v3/docs/videos), [키 발급](https://developers.google.com/youtube/registering_an_application).

## 인라인 HLS

확장은 기존 `SourceVideo.url`에 `data:application/vnd.apple.mpegurl;base64,...` 형식으로 길이가 정해진 HLS 미디어 목록을 반환할 수 있습니다. 바깥 주소의 `data://` 표기도 허용하며 새 확장 필드는 필요하지 않습니다.

UTF-8 목록 최대 512KiB, 조각 참조 10,000개, 서로 다른 인라인 AES-128 키 32개를 허용합니다. 키는 `data:application/octet-stream;base64,...`이며 정확히 16바이트여야 합니다. 조각·map 주소는 절대 HTTPS만 받고 기존 주소 검증·소스 프록시를 적용합니다. IV·시퀀스 번호·`METHOD=NONE` 전환을 유지합니다.

마스터·중첩 data·실시간 목록, HLS 변수, identity 외 암호화, 임의 data 자원, 인라인 목록의 원격 키 URI는 지원하지 않습니다. 확장이 먼저 미디어 형식을 선택하고 키를 확인해야 합니다. 일반 HTTPS·EDL은 유지합니다.

서버는 키·원격 자원을 프로필 범위의 재생 세션 URL로 바꿉니다. 키는 메모리에만 보관하며 응답은 `private, no-store`이고 세션 종료·만료 시 지웁니다. 인라인 원문을 웹 플레이어에 직접 전달하지 않습니다.

소스 검색과 재생에 같은 파서를 적용합니다. `Cookie`·`Authorization`은 유효한 `SourceVideo.originalUrl`의 정확한 HTTPS 출처에만 전달하고 다른 출처나 원본 미지정 시 제거합니다. Referer·User-Agent 등 비인증 헤더는 유지합니다. `originalUrl`로 상대 경로를 보완하지 않습니다.

빈 영상 결과는 `no-streams`, 결과는 있으나 지원 형식이 없으면 `unsupported-stream-format`을 반환합니다. 섞인 결과에서는 지원 형식만 남깁니다. 오류에 거부한 URL·목록·헤더를 포함하지 않으며 거부한 APK 작업 권한은 해제합니다. 실제 확장·플랫폼 호환성은 별도 확인이 필요합니다.
