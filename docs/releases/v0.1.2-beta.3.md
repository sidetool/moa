# MOA v0.1.2-beta.3

전체 회차 다운로드와 선택적인 AniList 추천 보강을 추가하고, 쇼츠 재노출·초기 버퍼와 홈 TOP 10을 개선했습니다. 정식 채널은 v0.1.1을 유지합니다.

## 주요 변경

- **선택 설치 플러그인 4개**: 한국 개봉·방영 일정, 찜한 작품 소식, 국내 극장 박스오피스, 작품 리뷰를 ZIP으로 제공합니다. 앱에 자동 설치되지 않습니다. 박스오피스는 서버의 KOBIS 키가 필요하며, 작품 리뷰는 TMDB 또는 키 없이 AniList 후보를 직접 선택해 조회합니다.

- **시즌 전체 다운로드**: 회차 목록 위에서 현재 시즌을 한 번에 대기열에 추가합니다. 회차 선택 화면이나 화질 팝업 없이 기존 설정을 사용하며, 이미 저장했거나 진행 중인 회차는 제외합니다. 관리자·다운로드 활성 상태에서만 표시합니다.
- **대기열 유지**: 아직 시작하지 않은 회차는 서버 재시작 후 이어서 다운로드합니다. 진행 중 끊긴 회차는 직접 재시도합니다. 대기 한도는 500개이며 저장 공간 부족 시 남은 대기열을 중단합니다.
- **AniList 애니 추천 보강**: 설정 → 홈 화면에서 선택적으로 켭니다. TMDB 추천이 부족할 때, 작품명·연도·형식이 일치하는 후보만 덧붙입니다. 기본은 꺼짐이며 TMDB 연결이 필요합니다. 기존 작품 ID와 기록은 유지합니다.
- **재생 실패 쇼츠 재노출 방지**: 재생할 수 없는 예고편이 계속 앞에 나오지 않도록 별도로 제외합니다. 일시 오류는 1시간, 재생 불가 작품은 설정 기간(최소 하루) 동안 숨깁니다. 본편 시청기록이나 취향에 반영하지 않습니다.
- **다운로드·쇼츠 버퍼 개선**: HLS 조각을 제한된 수로 병렬 수신합니다. 직접 재생 쇼츠에서는 다음 두 작품의 초기 영상·음성을 제한된 용량 안에서 준비합니다. 실제 속도는 소스와 네트워크에 따라 달라집니다.
- **오늘의 TOP 10 집계**: 현재 홈 탭에 설정된 소스들의 인기 순위를 합산합니다. 같은 작품은 기존 작품 연결 기준으로 묶고, 한 소스에서 중복 득표하지 않도록 했습니다. 실시간 시청자 집계나 일일 시청 통계는 아닙니다.

## 업데이트 참고

- 새 플러그인은 0.1.2-beta.3 이상에서 설치할 수 있습니다. 리뷰와 추천 보강은 AniList 요청 한도와 대기 시간을 공유합니다.
- 다운로드와 AniList 보강은 자동으로 켜지지 않습니다. 기존 저장본·설정·시청기록을 유지합니다.
- 대기열은 순차 실행되며, 다운로드를 끄면 남은 작업도 중단합니다. 한 번에 500개를 넘는 대기 등록은 거절합니다.
- AniList는 일부 확실히 연결되는 TV/영화 애니만 보강합니다. 모호한 시즌·동명 작품은 생략하며 어린이 프로필에서는 보강하지 않습니다. AniList 장애 시 기존 TMDB 추천을 사용합니다.
- 표준 이미지의 쇼츠는 기존 YouTube 임베드 방식입니다. 직접 재생은 별도 추출 도구를 준비한 서버의 선택적 실험 기능입니다.
- 개인 소스 확장이나 사이트별 데이터는 포함하지 않습니다. 모바일 PiP 자막·TV 인증은 이번 변경 대상이 아닙니다.
