# MOA v0.1.2-beta.2

다운로드 사용성과 예고편 재생을 개선하고, 선택적으로 켜는 쇼츠와 내 목록 기반 추천을 추가했습니다. 정식 채널은 v0.1.1을 유지합니다.

## 주요 변경

- **한 번 눌러 다운로드**: 회차마다 화질을 고르는 창 대신 설정한 화질로 바로 작업을 시작합니다. 다운로드 아이콘과 회차별 진행 상태를 표시하며, 작품별 묶기·접기와 선택 삭제를 유지합니다.
- **다운로드 명시적 활성화**: 기본은 꺼짐입니다. 관리자 설정에서 저장 폴더와 용량을 준비한 뒤 켜면 관련 UI가 나타납니다. 기존 저장본과 시청기록은 삭제하지 않습니다. beta.1에서 사용했다면 업데이트 후 설정에서 다시 켜 주세요.
- **예고편 대체 후보**: 재생할 수 없는 예고편은 다른 후보로 전환합니다. 선택적인 YouTube Data API 설정으로 삭제·비공개·퍼가기 제한을 미리 확인하고 지역 제한 후보의 우선순위를 낮춥니다. API 키 없이도 기존 재생을 사용할 수 있습니다.
- **쇼츠 — 실험**: 설정 → 실험 기능에서 프로필별로 켜는 예고편 피드입니다. 영화·시리즈·애니를 여러 개 고르고, 내 취향·인기·혼합 방식을 선택할 수 있습니다. 본 작품이나 직접 넘긴 작품은 기본 일주일 동안 다시 표시하지 않습니다. 본편 시청기록과는 별개입니다.
- **취향 기반 추천**: 시청기록과 내 목록을 함께 사용하고, 추천을 최대 40개까지 표시합니다. 이미 본 작품·내 목록·관심 없음은 추천 대상에서 제외하며, 추천 근거가 적으면 표시 개수도 적을 수 있습니다.
- **볼 목록 누락 수정**: 메인 홈에 선택하지 않은 소스의 저장 작품도 홈의 볼 목록에 나타납니다. 소스별 탭의 필터와 프로필·어린이 제한은 유지합니다.
- **플러그인 API**: 명시적 `watchlist.read` 권한으로 현재 프로필의 내 목록을 읽을 수 있습니다. 기존 플러그인에는 새 권한을 자동 부여하지 않습니다. 기록·내 목록 날짜 필터의 시간대 처리도 수정했습니다.

## 쇼츠 직접 재생에 관하여

일반 릴리스 이미지는 YouTube 임베드로 재생합니다. **직접 재생은 별도 추출 도구를 설치한 서버에서만 사용할 수 있는 추가 실험 기능**이며, 표준 이미지에 해당 도구를 넣거나 자동 활성화하지 않습니다.

직접 재생 환경에서는 다음 두 작품의 제한된 사전 준비, 자막·설정에 따른 번역, 탐색 막대, 길게 눌러 2배속, 설명 펼치기와 설정 내 최대 720p 화질 선택을 제공합니다. 준비 실패 시 앱 안의 YouTube 플레이어로 전환할 수 있습니다. 지역·인증·외부 서비스 변경에 따라 재생이 실패할 수 있고, 첫 준비 지연이 완전히 없어지는 것은 아닙니다. 자세한 설정은 [쇼츠 안내](https://github.com/sidetool/moa/blob/v0.1.2-beta.2/docs/SHORTS.md)를 참고하세요.

## 업데이트 참고

- v0.1.1 이상에서 베타 채널을 선택해 확인·수동 설치합니다. 예약·자동 설치는 없습니다.
- 다운로드를 꺼도 이미 저장된 파일과 기록은 유지합니다. `/downloads` 마운트와 관리자 용량 설정은 별도로 필요합니다. [서버 저장 안내](https://github.com/sidetool/moa/blob/v0.1.2-beta.2/docs/SERVER-SAVES.md)
- 쇼츠는 기본 꺼짐이며 어린이 프로필에서는 제공하지 않습니다. TMDB 연결이 필요합니다. YouTube Data API는 선택 사항입니다.
- AniList 연동, 모바일 PiP 자막 개선, TV 인증 개선은 이번 버전에 포함하지 않습니다.
- 비공개 확장·사이트별 진단 자료·사용자 데이터는 포함하지 않습니다.
