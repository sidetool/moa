# MOA v0.1.3-beta.1

v0.1.2 이후 재생 조작과 설정 화면, 요일별 신작 플러그인을 개선하고 서버·웹 구조와 문서를 정리했습니다.

## 재생·자막·번역

- **단축키 직접 설정**: 설정 → 조작에서 재생·탐색·음량·자막·속도 단축키를 바꾸고 현재 프로필과 기기에 저장할 수 있습니다.
- **길게 눌러 배속**: 영상 화면이나 Space를 길게 누르면 설정한 속도를 적용합니다. 마우스를 움직여도 유지하며 놓으면 원래 속도로 돌아갑니다.
- **다음 화와 미리보기**: 다음 화 안내·자동 전환 조건을 개선하고, 마우스를 움직이면 자동 전환을 멈추도록 했습니다. 재생 바 미리보기의 대기와 반복 처리를 줄이고 자막 알림은 조작 버튼이 숨겨져도 표시합니다.
- **자막 설정과 재사용**: ASS 원본 효과 유지 여부를 선택할 수 있으며 조절 간격을 기억합니다. 기본 간격은 5%입니다. 작품 묶기의 같은 시즌·회차에 저장된 온라인 자막을 재사용하고 동일한 자막의 중복 저장을 줄였습니다.
- **번역 설정**: API 키를 최대 20개까지 등록할 수 있습니다. 서비스 주소와 모델은 목록에서 선택하거나 ‘직접 입력’으로 설정합니다.

## 화면과 플러그인

- 버튼·선택 메뉴·입력·모달의 디자인과 애니메이션을 통일하고, 좁은 화면의 넘침과 정렬을 개선했습니다. 홈 탭은 길게 눌러 순서를 바꿀 수 있습니다.
- **요일별 신작 1.3.6**: 선택 설치 ZIP으로 제공합니다. 큰 포스터 아래에 시간과 제목을 표시하고, 원형 요일 버튼과 양옆 화살표로 탐색합니다. 작품이 정확히 연결되면 상세 페이지로 이동하며, 연결되지 않으면 제목을 검색합니다.
- 홈을 열 때 모든 요일의 작품 정보와 포스터를 제한된 수로 병렬 준비하며, 이미지 로딩 중에는 스켈레톤을 표시합니다. TMDB 포스터는 서버에 캐시해 새로고침과 서버 재시작 후에도 재사용합니다.
- 플러그인에서 TMDB 작품 정보와 포스터·연결된 작품을 조회할 수 있도록 API를 확장하고 제작 문서·템플릿을 갱신했습니다.

## 구조와 문서

- 공통 UI를 재사용 컴포넌트로 정리하고 스타일을 Sass로 전환했습니다. 서버·웹 코드를 기능별로 나누고 서버 전용 패키지와 번역 제공자를 관련 모듈로 정리했습니다.
- 설치·사용·개발 문서를 주제별로 합치고 한국어 안내와 디자인 시스템 미리보기를 정리했습니다.

## 업데이트 참고

- 설정 → 정보에서 사전 릴리스 채널을 선택해 확인·설치합니다. 안정 채널은 안정 릴리스만, 사전 릴리스 채널은 사전 릴리스만 표시합니다.
- 정식 버전 설치·기존 설치 연결·추가 기능 설치에서 버전을 찾지 못하던 문제를 수정했습니다.
- 요일별 신작은 설치된 플러그인도 별도로 업데이트해 주세요. 포스터에는 서버의 TMDB 연결이 필요하며, 서버 캐시는 30일이 지나거나 용량 정리로 삭제되면 다시 가져옵니다.
