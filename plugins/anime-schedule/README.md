# 요일별 신작

MOA 홈에 월·화·수·목·금·토·일 애니메이션 편성표를 표시하는 웹사이트 플러그인.

## 기능

- 한국 시간 기준 오늘 요일을 먼저 표시함.
- 요일을 선택하면 해당 요일의 작품명과 방영 시간을 가져옴.
- 결방과 첫 방송 예정일을 표시하고, 방영 종료일이 지난 작품은 제외함.
- 작품을 선택하면 MOA 검색 화면에서 해당 작품을 검색함.
- 요일별 응답을 홈 화면에 머무는 동안 기억하고, 새로고침으로 다시 가져옴.
- 키보드 방향키와 Home·End 키로 요일을 이동할 수 있음.

데이터 출처는 [Anissia](https://anissia.net)이며, [공개 편성표 API](https://github.com/anissia-net/document/blob/main/api_anime_schdule.md)를 사용함. 한국 시간 기준 방영 일정으로, MOA에 설치한 미디어 소스의 실제 업로드 여부나 시각과 다를 수 있음. 특정 소스의 업로드나 재생 가능 여부를 보장하지 않음.

## 설치

홈 배치와 `moa.ui.resize()`를 지원하는 MOA가 필요함. 관리자 계정으로 **플러그인 → 폴더 선택**에서 이 폴더를 선택해 설치하고 활성화하면 홈에 표시됨.

ZIP으로 설치하려면 저장소 루트에서 기존 템플릿 빌드 도구를 실행함.

```sh
node plugins/template/build.mjs ../anime-schedule
```

생성된 `plugins/template/dist/anime-schedule.zip`을 플러그인 화면에서 설치하면 됨.

## 권한

| 권한 | 용도 |
| --- | --- |
| `app.navigate` | 선택한 작품의 MOA 검색 화면으로 이동 |
| `ui` | 홈에 표시하는 플러그인 높이 조정 |
| `https://api.anissia.net` | 편성표 API 조회 |

외부 이미지를 가져오거나 미디어 소스·계정·프로필 데이터에 접근하지 않음. API 응답은 텍스트로 표시하고 MOA의 네트워크 요청과 iframe 격리를 그대로 사용함.
